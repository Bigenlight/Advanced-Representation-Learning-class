## Why Does Multi-Stage Alignment Fail? (p.57)

**슬라이드 내용**
- Multi-stage alignment
  - Align representations at several backbone stages.
  - Helpful on a generic dataset (Caltech).
  - Harmful on a fine-grained dataset (CUB).
- 우상단 그림: 자동차 이미지 → Low-Level Feature → Mid-Level Feature → High-Level Feature → Trainable Classifier 로 이어지는 화살표 파이프라인. 각 단계 아래에 해당 단계 필터/활성화 시각화 패치 격자가 있음 (low: 색/에지 같은 단순 패턴, mid: 질감/곡선, high: 객체 부분 형태). 출처 표기: bengio talks DL-Tutorial-NIPS2015.pdf.
- 하단 그래프 2개 (x축: epochs 0–100, y축: average angle (°)). 범례: MoCo v2 (빨간 점선), Supervised (파란 실선), MoCo v2 with multi-stage alignment (검은 점선), MoCo v2 with our SPA (초록 일점쇄선).
  - (a) Training on Caltech-256: y축 약 84.5–87.5. Supervised가 가장 높고(~87), multi-stage alignment(검정)가 MoCo v2(빨강, ~86.7)보다 높아져 supervised에 근접(~87.1). 즉 alignment가 angle을 키워 도움이 됨.
  - (b) Training on CUB200: y축 약 68–80. Supervised ~78.3, SPA(초록) ~77.7로 supervised에 근접, MoCo v2 ~75.8, multi-stage alignment(검정)는 epoch가 지날수록 ~74에서 ~69까지 계속 **하락**.
- 그래프 설명 텍스트: The vertical axis: the average angle between different image representations.
  - Larger angle → Different samples are better separated.
  - Smaller angle → Representations are clustered closer together.
- 질문(굵은 글씨): **Why does the same alignment strategy fail on fine-grained data?**

**설명**
- y축 **average angle**은 서로 다른 이미지 representation 사이의 평균 각도로, representation space에서 샘플들이 얼마나 퍼져(separated) 있는지의 지표임. 각도가 클수록 샘플 간 구분이 잘 됨(uniformity가 좋음), 작을수록 서로 뭉쳐 있어 구분력이 떨어짐.
- Supervised(파란선)는 label을 쓰므로 angle이 가장 크고, 이를 SSL 방법이 얼마나 따라가는지가 비교 기준임.
- **Multi-stage alignment**는 backbone의 마지막 층뿐 아니라 여러 stage의 feature에도 positive pair 정렬(alignment) loss를 주는 방식임. generic dataset(Caltech-256)에서는 shallow stage에도 같은 감독 신호를 주니 angle이 커지고 성능이 좋아짐.
- 그러나 fine-grained dataset(CUB200)에서는 오히려 angle이 계속 감소 → 샘플들이 뭉쳐 **collapse**에 가까워짐. 즉 shallow stage에 deep stage와 똑같이 positive pair를 강제로 맞추는 것이 해로움.
- 이유의 단서는 우상단 그림: **shallow(low-level) feature는 색·에지·질감 같은 저수준 정보**이고 deep feature가 semantic을 담음. fine-grained에서는 클래스 간 차이가 작아 저수준 단서도 구분에 중요할 수 있는데, 강한 augmentation을 거친 positive pair의 shallow feature는 서로 크게 달라지므로(p.58) 이를 억지로 일치시키는 것이 해로운 것으로 추정됨(슬라이드는 질문만 던지고 답은 다음 슬라이드에서 제시) → 다음 슬라이드(p.58)에서 원인을 분석함.
- 초록 일점쇄선 "MoCo v2 with our SPA"는 제안 기법(Stage-wise Progressive Augmentation, p.59)을 미리 보여주는 것으로, fine-grained에서도 angle이 올라 supervised에 근접함.
- 이 슬라이드의 흐름: 문제 제기(기존 multi-stage alignment 실패) → 원인 분석(p.58) → 해법(p.59–61).

> 보충: 이 슬라이드는 슬라이드 하단의 Figure 번호/논문명이 명시되지 않음. 이후 슬라이드에서 PAPN 논문의 Figure 2, Table 1/3, Figure 5가 인용되므로 같은 논문(PAPN)의 분석 figure로 보임. 논문 저자·연도는 슬라이드에 없음.

## Strong Augmentation Changes Shallow Features (p.58)

**슬라이드 내용**
- 그림(Figure 2): 꺾은선 그래프. x축: incremental augmentations $\phi_0, \phi_1, \phi_2, \phi_3, \phi_4, \phi_5$ (증가하는 augmentation 강도), y축: average angle (°), 범위 0–20. 세 곡선:
  - stage-2 (파란 실선, 원 마커): $\phi_0$ ~0.7° → $\phi_1$ ~2.6° → $\phi_2$ ~5.7° → $\phi_3$ ~9.5° → $\phi_4$ ~14.5° → $\phi_5$ ~20°.
  - stage-3 (초록 점선, x 마커): 약 0.8 → 1.7 → 3.5 → 5.8 → 8.8 → 12.2°.
  - stage-4 (빨간 일점쇄선, 삼각형 마커): 약 0.5 → 1.6 → 2.7 → 4.0 → 5.7 → 7.8°.
- 캡션: Figure 2. The average angle between embeddings and their positive views, generated by different stages of $f_q$ and $f_k$. The horizontal axis represents a set of incremental augmentations defined in Section 3. As the intensity of augmentations increases, the average angles at different stages steadily rise.
- 우측 bullet:
  - Stronger augmentation increases positive-pair disagreement.
  - Shallow stages are affected more severely.
  - Deep stages are relatively augmentation-tolerant.
- When strong augmentation is applied,
  - shallow layers perceive two photos of the same bird as different entities.
  - In contrast, deep layers are relatively less affected because they focus on the overall semantic meaning.
- → One augmentation strength does not fit every stage.

**설명**
- 여기서 average angle은 한 이미지의 embedding과 그 **positive view**(같은 이미지를 augmentation한 것)의 embedding 사이 각도임. 앞 슬라이드(서로 다른 이미지 간 각도 = 분리도)와 달리 **같은 이미지 쌍 간 불일치**를 재는 값이므로 작을수록 좋음 (positive가 일관됨).
- $f_q$, $f_k$는 MoCo 계열의 query encoder와 (momentum) key encoder임.
- 해석: augmentation 강도 $\phi_0 \to \phi_5$가 커질수록 모든 stage에서 positive pair 간 각도가 증가함. 그런데 증가 폭이 **stage-2(shallow) > stage-3 > stage-4(deep)** 순으로 커서, $\phi_5$에서 stage-2는 ~20°, stage-4는 ~8°임. 즉 shallow feature는 crop, color jitter, grayscale 같은 입력 변화에 직접 민감(pixel/texture 기반)하고, deep feature는 semantic을 요약해 변화에 강건함.
- 결론: 같은 강도의 augmentation으로 만든 positive pair를 모든 stage에서 똑같이 정렬시키는 것은 부적절함. shallow stage에는 view가 서로 다른 객체처럼 보여서 정렬이 억지가 되고(p.57의 angle 감소 원인), deep stage는 강한 augmentation도 견딤.
- 이것이 **Stage-wise Progressive Augmentation**(p.59)의 동기: **stage별로 견딜 수 있는 augmentation 강도에 맞춰 positive pair를 만든다.**

> 보충: "incremental augmentations $\phi_0 \sim \phi_5$"의 구체적 구성(어떤 변환을 어떤 순서로 추가하는지)은 논문 Section 3에 정의되어 있다고 캡션이 말하며 슬라이드에는 없음. p.59 그림에서 view $s_1$(약한 변환), $s_2$, $s_3$(grayscale 포함)로 점점 강해지는 것이 그 예시로 보임.

## PAPN: Two Ideas for Fine-Grained SSL — ① Stage-wise Progressive Augmentation (p.59)

**슬라이드 내용**
- 그림 제목: **Stage-wise Progressive Augmentation**. 좌우 대칭 구조의 다이어그램:
  - 왼쪽(분홍, query 경로): 원본 새 이미지 → "Progressive Augmentation" 박스에서 3개 view $s_1, s_2, s_3$ 생성 (점점 강해지는 변환; $s_3$는 grayscale). 각 view가 서로 다른 깊이의 encoder로 들어감: $s_1 \to$ Stage 1,2 → projection head $g_2^q$ → $\boldsymbol{z}_2^q$; $s_2 \to$ Stage 1,2,3 → $g_3^q$ → $\boldsymbol{z}_3^q$; $s_3 \to$ Stage 1,2,3,4 → $g_4^q$ → $\boldsymbol{z}_4^q$.
  - 오른쪽(파랑, key 경로): 같은 구조로 원본 이미지의 다른 progressive view들(마찬가지로 $s_1, s_2, s_3$)이 Stage 1,2 / 1,2,3 / 1,2,3,4 → $g_2^k, g_3^k, g_4^k$ → $\boldsymbol{z}_2^k, \boldsymbol{z}_3^k, \boldsymbol{z}_4^k$.
  - 가운데 "Stage-wise Semantic Alignment" 박스: 같은 stage 단계끼리 $\boldsymbol{z}_i^q \leftrightarrow \boldsymbol{z}_i^k$ 를 초록 양방향 화살표로 정렬.
- ① Stage-wise Progressive Augmentation
  - Mild augmentation for shallow stages
  - Strong augmentation for deep stages
  - Stage-wise semantic alignment
- 수식:
$$\mathcal{L}_{SPA} = \sum_{i=1}^{T} \left\| \hat{\boldsymbol{z}}^{k}_{L-T+i} - \hat{\boldsymbol{z}}^{q}_{L-T+i} \right\|_2^2,\quad \text{where } \hat{\boldsymbol{z}} = \boldsymbol{z}/\|\boldsymbol{z}\|_2.$$
- 굵은 글씨: **Positive pairs are created based on the intensity of augmentation that each stage can withstand.**

**설명**
- 핵심 설계: p.58의 관찰(shallow일수록 augmentation에 민감)을 반영해 **shallow stage는 약한 augmentation view, deep stage는 강한 augmentation view**의 positive pair로 정렬함. 그림에서 $s_1 < s_2 < s_3$ 순으로 변환 강도가 커지고, 더 깊은 stage까지 통과시킨 feature가 더 강한 view와 짝지어짐(Stage 1,2에는 mild $s_1$, Stage 1~4에는 strong $s_3$).
- 기호 의미
  - $L$: backbone의 총 stage 수(그림 기준 $L=4$), $T$: 정렬에 사용하는 마지막 stage 개수(그림 기준 $T=3$, 즉 $i=1,2,3$에 대해 인덱스 $L-T+i$ = 2,3,4, 곧 stage 2, 3, 4의 embedding을 정렬).
  - $\boldsymbol{z}^q_j, \boldsymbol{z}^k_j$: j번째 stage 출력에 projection head $g_j$를 통과시킨 query/key embedding.
  - $\hat{\boldsymbol{z}} = \boldsymbol{z}/\|\boldsymbol{z}\|_2$: L2 normalization.
- loss 직관: normalized 벡터 간 squared L2 거리는 $\|\hat a - \hat b\|_2^2 = 2 - 2\cos\theta$ 이므로, **cosine similarity를 최대화(각도를 최소화)**하는 것과 동치임. 즉 BYOL/SimSiam류의 정렬 손실과 같은 형태로, negative 없이 positive 쌍만 맞추는 **alignment term**.
- 이전 방법(p.57 multi-stage alignment)과의 차이: 이전엔 모든 stage에 **같은 강도**의 augmentation view를 쓰고 정렬했으나, SPA는 **stage마다 다른 강도**를 써서 shallow feature가 지나친 augmentation으로 망가지는 것을 막음. 이 결과 p.57 (b)의 초록선처럼 fine-grained에서도 angle이 유지/상승함.
- 왜 query/key 양쪽에 같은 구조? MoCo처럼 $f_q$(gradient 업데이트)와 $f_k$(momentum 업데이트)가 짝을 이루어 각 stage 출력끼리 정렬하기 때문임.

> 보충: 그림의 stage-wise "Stage 1,2 / 1,2,3 / 1,2,3,4"는 서로 다른 별개 네트워크가 아니라 같은 backbone의 앞부분을 각 view에 대해 통과시킨 것(중간 feature를 projection head로 추출)으로 해석됨. 정확한 구현(하나의 view로 여러 stage를 동시에 읽는지, view별로 forward를 따로 하는지)은 슬라이드만으로는 확정 불가.

## PAPN: Two Ideas for Fine-Grained SSL — ② Prototype-based Holistic-Partial Learning (1) (p.60)

**슬라이드 내용**
- 그림 제목: **Prototype-based Holistic-Partial Contrastive Learning**.
  - 왼쪽: 원본 새 이미지에서 View1(컬러)과 View2(grayscale)를 생성. View1 → Encoder $f_q$ (분홍), View2 → Encoder $f_k$ (파랑). $f_q$에서 $f_k$로 "Momentum Update" 화살표.
  - 중앙: 두 encoder 출력이 "Prototype Clustering" 박스(색 막대 여러 개 = 학습되는 prototype들)로 들어감. 각 encoder에서 $\boldsymbol{v}^{\text{whole}}$(전체 feature 막대)와 $\boldsymbol{v}^{\text{part}}$(prototype에서 얻은 part feature)가 나와 결합된 뒤 projection head $\text{proj}_q$ / $\text{proj}_k$ → $\boldsymbol{q}^{\text{wp}}$, $\boldsymbol{k}_+^{\text{wp}}$. 이 둘 사이를 "Holistic-Partial Contrastive Learning"으로 대조.
  - 우측 상자(Prototype Clustering 확대): 최종 feature map의 공간 위치 벡터 $\boldsymbol{x}_1, \ldots, \boldsymbol{x}_{HW}$ 와 prototype $\boldsymbol{p}_1$ 의 유사도(원 모양 연산)를 가중치로 곱($\times$)한 뒤 합($+$)하여 $\boldsymbol{a}_1$ 생성. 같은 연산을 $\boldsymbol{p}_N$까지 반복해 $\boldsymbol{a}_N$ 생성. 아래에 $\boldsymbol{v}^{\text{part}}$ 막대(여러 색이 섞인 형태)와 "Prototype Clustering" 라벨.
- ② Prototype-based Holistic-Partial Learning
  - Learn prototypes from spatial descriptors
    - View the final feature map as a set of spatial descriptors.
  - Extract part-level representations
  - Combine global and local information
- 수식 (왼쪽):
$$\boldsymbol{X}_L = [\boldsymbol{x}_1, \boldsymbol{x}_2, \ldots, \boldsymbol{x}_{HW}]$$
$$\boldsymbol{P} = [\boldsymbol{p}_1, \boldsymbol{p}_2, \ldots, \boldsymbol{p}_N]$$
$$\boldsymbol{M} = \hat{\boldsymbol{P}}^\top \hat{\boldsymbol{X}}_L \quad \text{(Prototype similarity)}$$
- 수식 (오른쪽, Part representation):
$$\boldsymbol{A} = \boldsymbol{X}_L \boldsymbol{M}^\top = [\boldsymbol{a}_1, \boldsymbol{a}_2, \ldots, \boldsymbol{a}_N]$$
$$\boldsymbol{v}^{\text{part}} = \frac{\sum_{i=1}^{N} \boldsymbol{a}_i}{N}$$

**설명**
- 아이디어: fine-grained 인식은 부리·날개·꼬리 같은 **part**가 중요(p.56)하므로, 전체 pooling 벡터 외에 part-level 표현을 따로 만들어 같이 쓰자는 것임.
- 최종 stage feature map $(H \times W \times C)$을 $HW$개의 **spatial descriptor** $\boldsymbol{x}_j \in \mathbb{R}^C$ 집합 $\boldsymbol{X}_L$로 봄(공간 위치마다 하나의 local feature).
- $\boldsymbol{P}$는 **N개의 learnable prototype**($\boldsymbol{p}_i \in \mathbb{R}^C$)로, 각각이 어떤 반복되는 시각 패턴(예: 새의 머리 질감, 날개 무늬)을 대표한다고 기대함.
- $\boldsymbol{M} = \hat{\boldsymbol{P}}^\top \hat{\boldsymbol{X}}_L$: 정규화된($\hat{\cdot}$) prototype과 spatial descriptor 간 **cosine similarity 행렬** ($N \times HW$). 각 prototype이 이미지의 어느 위치에서 강하게 반응하는지를 나타내는 **attention/heatmap** 역할(p.63에서 시각화).
- $\boldsymbol{A} = \boldsymbol{X}_L \boldsymbol{M}^\top$: 각 prototype $i$에 대해 유사도를 가중치로 spatial descriptor들을 **가중합**하여 part representation $\boldsymbol{a}_i$를 얻음. 즉 "prototype $i$와 비슷한 위치들의 feature를 모은 것" = 해당 part의 표현.
- $\boldsymbol{v}^{\text{part}}$: N개 part 표현의 **평균**. 그림의 우측 상자가 이 계산을 시각화한 것(각 prototype마다 $\times$로 가중, $+$로 합산).
- 이 과정이 spatial descriptor를 prototype에 soft assignment하는 **clustering**과 유사해서 그림에서 "Prototype Clustering"이라 부름. 라벨 없이도 이미지 내 반복 패턴을 part로 발견함.
- $\boldsymbol{x}$와 $\boldsymbol{X}_L$ 표기: $\boldsymbol{M}$ 정의에서는 $\hat{\boldsymbol{X}}_L$ (정규화), $\boldsymbol{A}$ 정의에서는 정규화 안 된 $\boldsymbol{X}_L$ 사용 — 슬라이드 표기 그대로이며 의도된 것으로 보임.

> 보충: 슬라이드는 prototype $\boldsymbol{P}$가 어떻게 학습되는지(gradient로 직접 학습? EMA? clustering 알고리즘?) 명시하지 않음. "learnable prototypes"(p.64)라 했으므로 loss를 통해 학습되는 파라미터로 보이나 정확한 업데이트 방식은 논문 확인 필요.

## PAPN: Two Ideas for Fine-Grained SSL — ② Prototype-based Holistic-Partial Learning (2) (p.61)

**슬라이드 내용**
- 상단 그림은 p.60과 동일한 Prototype-based Holistic-Partial Contrastive Learning 다이어그램.
- 수식:
$$\boldsymbol{v}^{\text{whole}} = \left[\text{pool}(\boldsymbol{X}_{L-T+1}); \ldots; \text{pool}(\boldsymbol{X}_L)\right],$$
$$\boldsymbol{v}^{\text{wp}} = [\boldsymbol{v}^{\text{whole}}; \boldsymbol{v}^{\text{part}}].$$
- 우측 bullet:
  - Whole feature: overall object appearance
  - Part feature: local discriminative patterns
  - Concatenated representation enters InfoNCE
- 손실:
$$\mathcal{L}_{PHP} = -\log \frac{\exp(\boldsymbol{q}^{\text{wp}} \cdot \boldsymbol{k}_+^{\text{wp}} / \tau)}{\sum_{i=0}^{K} \exp(\boldsymbol{q}^{\text{wp}} \cdot \boldsymbol{k}_i^{\text{wp}} / \tau)},$$
- 굵은 글씨: **Do not choose between global and local features—contrast both together.**

**설명**
- $\boldsymbol{v}^{\text{whole}}$: 마지막 $T$개 stage($L-T+1 \ldots L$)의 feature map을 각각 global pooling한 뒤 **concatenate**(;는 연결). p.59의 SPA가 쓰는 stage 범위와 같음. 여러 깊이의 holistic(전체) 정보를 담음 → 객체 전체의 모양/외형.
- $\boldsymbol{v}^{\text{part}}$ (p.60): prototype으로 뽑은 part-level 지역 정보 → 변별적인 local pattern.
- $\boldsymbol{v}^{\text{wp}} = [\boldsymbol{v}^{\text{whole}}; \boldsymbol{v}^{\text{part}}]$: 둘을 concatenate. 이를 projection head ($\text{proj}_q$, $\text{proj}_k$)에 통과시켜 $\boldsymbol{q}^{\text{wp}}, \boldsymbol{k}^{\text{wp}}$를 얻고 **InfoNCE**에 넣음 (p.60 그림의 $\boldsymbol{q}^{\text{wp}}, \boldsymbol{k}_+^{\text{wp}}$).
- $\mathcal{L}_{PHP}$는 표준 MoCo형 InfoNCE임: $\boldsymbol{q}^{\text{wp}}$와 positive key $\boldsymbol{k}_+^{\text{wp}}$의 유사도(온도 $\tau$로 나눔)를 분자로, queue의 $K$개 negative를 포함한 전체 key $\boldsymbol{k}_0 \ldots \boldsymbol{k}_K$와의 유사도 합을 분모로 둠. 분모의 $i=0$ 항이 positive 자신으로 보임 (MoCo 관례). 
- 메시지: global feature와 local feature 중 **하나를 고르지 않고 둘을 합쳐서 함께 대조**함. generic 인식은 global만으로 충분하지만 fine-grained에선 part가 필수(p.56) → 두 정보를 모두 contrastive 표현에 반영.
- 이전 방법과의 차이: 기존 MoCo는 global pooling 벡터 하나만 InfoNCE에 사용 → 미세한 part 단서가 평균에 묻힘. PHP는 part를 명시적으로 추출해 InfoNCE의 입력에 포함시켜 part 수준의 구분력을 contrastive 학습에 직접 반영함.

> 보충: InfoNCE의 $K$는 MoCo의 queue 크기(negative 수)이고 $\tau$는 temperature. 슬라이드는 $K$, $\tau$를 따로 정의하지 않음. 분모의 합 인덱스가 $i=0$부터인 것은 positive를 포함하기 위한 표기로 추정됨 (슬라이드 원문 유지).

## EXAM POINTS

1. **Multi-stage alignment가 fine-grained(CUB)에서 실패하는 이유**: shallow stage는 강한 augmentation에 민감(Figure 2)해서 positive pair의 shallow feature를 강제로 맞추면 오히려 변별적인 저수준 단서가 사라지고 representation이 뭉침(average angle 감소).
2. **Average angle 지표의 두 가지 쓰임**: p.57은 서로 다른 이미지 간 각도(클수록 분리 좋음), p.58은 anchor와 그 positive view 간 각도(작을수록 일관). 구분해서 해석할 것.
3. **Stage-wise Progressive Augmentation(SPA)**: shallow에는 mild, deep에는 strong augmentation으로 positive 생성, stage별 정렬. 수식 $\mathcal{L}_{SPA}=\sum_{i=1}^{T}\|\hat z^k_{L-T+i}-\hat z^q_{L-T+i}\|_2^2$ 와 normalized squared L2 = $2-2\cos$ 임을 설명.
4. **Prototype-based part representation 유도**: $\boldsymbol{M}=\hat{\boldsymbol P}^\top\hat{\boldsymbol X}_L$ (cosine similarity) → $\boldsymbol{A}=\boldsymbol{X}_L\boldsymbol{M}^\top$ (가중합) → $\boldsymbol{v}^{\text{part}}=\frac1N\sum\boldsymbol a_i$. 각 기호와 차원 의미.
5. **PHP의 whole + part 결합**: $\boldsymbol v^{\text{wp}}=[\boldsymbol v^{\text{whole}};\boldsymbol v^{\text{part}}]$를 InfoNCE에 입력. 왜 global만으로는 부족한가(fine-grained는 part가 중요)에 답할 수 있어야 함.
6. **Ablation 수치**: baseline 63.98 → SPA +3.67, PHP +3.93, 둘 다 +5.95 (top-1). 두 모듈은 상호 보완적이나 단순 합보다 작음(sub-additive).
7. **Generic vs fine-grained 인식 차이**: "Is this a bird?"는 global shape으로 충분, "Which species?"는 부리/머리/날개/꼬리 같은 part 필요 → holistic + part-level 표현 모두 필요.
8. **PAPN의 3가지 기여 요약**: (1) augmentation 강도를 feature depth에 맞춤, (2) learnable prototype으로 local pattern 발견, (3) whole+part feature를 InfoNCE에서 함께 대조.
