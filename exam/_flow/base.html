Teacher – student

Student · teacher= online·target, query·key
같은 구조의 네트워크 두 개. gradient는 student만 받고, teacher는 student를 천천히 따라가. 방법마다 이름만 달라.
EMA · momentum update
θt ← m·θt + (1−m)·θs, m은 0.99–0.999 정도.target network의 Polyak(soft) update와 같은 식. SAC의 τ = 0.005는 m = 0.995인 셈.
Stop-gradient · detach
target 쪽으로는 gradient를 안 흘려.TD target r + γQtarget에 gradient를 안 흘리는 semi-gradient와 같은 이유. 움직이는 target을 쫓다가 무너지지 않게.
Distillation
teacher의 출력(보통 확률 분포)을 student가 따라 하게 학습하는 것.

시험 함정 · 기호 하나에 뜻 여러 개

  • BYOL의 τ: EMA 계수. temperature 아님.
  • FixMatch의 τ: confidence threshold.
  • DINO 코드의 l: 숫자 1이 아니라 소문자 L (teacher momentum).

80p

질문label 없이 supervision을 만들 수 있나?

답은 "data를 일부러 망가뜨리고, 원래대로 맞히게 하자"야. 회전 각도를 맞히려면 물체가 뭔지 알아야 하니까 encoder가 똑똑해진다는 논리.

Why SSLp.3–10

문제label이 비싸 (ImageNet 14M장 = 22 human years). hashtag·GPS 같은 semi-automatic label은 noisy하고, video·long tail·의료 같은 새 domain은 label 달기가 더 어려워.

정의p.11–17, p.20

핵심"obtain labels from the data itself", "predict part of the data from other parts". pretext task로 encoder를 학습하고 downstream task로 transfer.

차이unsupervised(clustering, PCA)와 달리 data에서 자동으로 만든 명시적 예측 target이 있어.

평가p.18, p.46, p.48

핵심pretext 성능이 아니라 downstream 성능으로 평가해. frozen feature 위에 shallow(linear) head만 학습.

포인트negative 구성이 핵심이고, curriculum (easy negative 먼저 → hard negative 섞기)이 제일 좋아.

Invariance vs Equivariancep.71–75

Invariancef(t(x)) = f(x). 변환해도 표현이 안 변해.

Equivariancef(t(x)) = φ(t, f(x)). 표현이 예측 가능하게 변해.

포인트분류엔 invariance가 좋지만 detection은 위치 정보, 꽃 분류는 색 정보가 필요해. pretext가 어떤 정보를 남길지를 정해.

STLYu, NeurIPS 2024 · p.76–79

핵심loss 3개. 같은 이미지·다른 변환 (invariant), 다른 이미지·같은 변환 (transformation representation 학습), 학습한 변환을 적용해서 예측 (equivariant).

차이변환 label(parameter) 없이 변환 표현을 배워.

RL로 번역

pretext task는 RL의 auxiliary task랑 같은 발상이야 (본 목적은 아니지만 encoder를 키우는 보조 과제). 엣지 연속성이나 색 통계로 jigsaw를 풀어 버리는 shortcut은 reward hacking이랑 비슷한 냄새가 나. 그리고 invariance vs equivariance는 로봇에서 특히 중요해. grasp하려면 물체의 위치·방향이 필요한데, crop·flip에 무조건 invariant하게 배우면 그 정보가 날아가.

시험 함정
  • Colorization은 regression이 아니라 classification (313 bins).
  • Jigsaw는 9! 전부가 아니라 64개 순열 (pairwise Hamming distance 최대).
  • Inpainting에서 L2만 쓰면 blurry, adversarial만 쓰면 선명하지만 context와 안 맞아.
  • SSL 평가는 pretext 정확도가 아니라 downstream 성능.
다음으로

pretext는 사람이 일일이 설계해야 하고 마지막 layer가 그 과제에 특화돼. 그래서 "같은 건 가깝게, 다른 건 멀게"라는 일반 원리로 가. → L03

Mean Teacher의 θ′ ← βθ′ + (1−β)θ는 target network soft update 그대로고, β를 0.99 → 0.999로 키우는 것도 "초반엔 빨리 따라가고 나중엔 안정적으로"라는 같은 직관이야. consistency regularization은 DrQ·RAD가 pixel RL에서 하는 것(augmentation을 줘도 Q·policy가 같게)과 같은 발상이고, sim2real의 domain randomization도 "겉모습이 바뀌어도 행동은 같아야 한다"는 점에서 친척이야. pseudo labeling은 자기 예측으로 자기 target을 만드는 bootstrapping이야. confirmation bias는 Q-learning에서 자기 추정치로 target을 만들 때 오차가 쌓이는 문제랑 같은 모양이고, 해법도 닮았어. DivideMix가 두 network의 분할을 서로 바꿔 쓰는 건 Double DQN·TD3 twin critic처럼 "다른 estimator로 내 target을 견제"하는 발상이야. 시험 함정

로봇 쪽 teacher–student는 보통 privileged 정보를 가진 teacher를 student로 distill하는 거야 (RMA, Learning by Cheating). 이 수업의 teacher는 대부분 student의 EMA 복사본이야 (BYOL, DINO, Mean Teacher). 시험장에서 네 직관이 오히려 헷갈리게 만들 수 있으니 조심해.

마지막 체크: 이 12줄은 영어로 바로 나와야 해

  1. MoCo: the key encoder is a momentum encoder; gradients flow only through the query encoder.
  2. SimCLR: 2N−2 in-batch negatives; after training, throw away g and use f.
  3. BYOL: no negatives; online network with a predictor, EMA target, MSE.
  4. DINO: student matches the EMA teacher's centered + sharpened softmax with cross-entropy.
  5. Barlow Twins: cross-correlation matrix → identity (invariance + redundancy reduction).
  6. CLIP: symmetric loss over an N×N matrix, labels = np.arange(n), zero-shot via text prompts.
  7. SwAV: swapped prediction of codes; Feature ↔ Prototype.
  8. Temporal Ensembling = EMA of predictions; Mean Teacher = EMA of weights.
  9. VAT: "virtual" = the model's own prediction instead of the ground-truth label.
  10. MixMatch: average over K augmentations → sharpen → MixUp; L2 loss for unlabeled data.
  11. FixMatch: weak → confidence threshold → strong, cross-entropy; no sharpening, no MixUp.
  12. DivideMix: GMM on per-sample loss; each network uses the other network's clean/noisy division.
