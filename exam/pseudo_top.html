11개를 꿰는 공통 패턴

  • detach = stop-gradient = target 쪽 고정: MoCo(key) · DINO(teacher) · X-CLR(text). 한 단어로 세 곳을 커버해.
  • momentum / EMA = 느린 쪽이 빠른 쪽을 따라감: MoCo key encoder · DINO teacher · BYOL target. TE만 prediction의 EMA야 (weight 아님).
  • 두 view 만들기: SimCLR · MoCo · DINO는 augmentation 두 번, Π-model은 dropout까지 다르게 해서 두 번 forward.
  • labels: MoCo zeros(N) (positive가 0번 칸) ↔ CLIP arange(n) (대각선).

아래 카드: 노란 형광펜 = 1순위 빈칸 줄, 파란 점선 = 2순위. 그림을 누르면 원본 크기로 열려.

X-CLR

L03 p.67 ★★ 나올 수도

InfoNCE의 one-hot 정답 대신, frozen text encoder로 만든 caption끼리의 similarity(soft target graph)를 image 쪽이 따라가게 해.

빈칸
tgt_sims = softmax( @ txt_emb.T / tao_s, dim=1)인정: text embedding (caption 쪽 embedding)
왜
target graph = text끼리의 similarity야. image 쪽(img_emb)은 학습되는 쪽이고, 그 분포를 CE로 맞춰 (CE(tgt_sims, img_sims)).
어느 방법?
txt_enc(captions).detach() + softmax(... / tao_s)로 만든 soft target + return CE(tgt_sims, img_sims)
2순위
txt_emb = txt_enc(captions).() # N x D_txt (주석 "frozen text encoder" → target 쪽은 gradient 차단)
버려도 됨
tao vs tao_s 구분, shape 주석, 아래 p_ij · s_ij · G(soft) 수식

SimCLR Alg.1

L04 p.25 ★★★ 꼭 나온다

같은 이미지에 augmentation을 두 번 → 두 view가 positive, batch 안 나머지 2N−2개가 negative. 학습이 끝나면 projection head g는 버려.

빈칸
draw two functions t∼T, t′∼T인정: data augmentation
왜
label 없이 positive pair를 만드는 줄이야. 교수님이 빨간 박스 + "Generate a positive pair by sampling data augmentation functions"를 직접 달았어.
어느 방법?
h = f(x̃) # representation, z = g(h) # projection, 마지막 줄 return encoder network f(·), and throw away g(·). queue·momentum 없음.
2순위
return encoder network f(·), and throw away (인정: g, projection head. downstream엔 h = f(x)를 써)
버려도 됨
ℓ(i,j) 식 전체, 1/2N Σ[…] 평균 식, s_ij cosine 식, 2k−1 / 2k 인덱스

BYOL 단계 (준-알고리즘)

L04 p.32 ★★ 나올 수도

negative 없이 online network가 target network(online의 EMA) 출력을 예측해. 학습되는 건 online(θ)뿐이야.

빈칸
BYOL does not use pairs.인정: negative samples
왜
SimCLR·MoCo와 갈리는 BYOL의 정체성이야. 슬라이드 맨 아래 굵은 글씨라 T/F로도 나오기 좋아 ("BYOL uses negative pairs" → F).
어느 방법?
online에만 있는 prediction q_θ, "loss is MSE between L2-normalized prediction and z̄′", "only parameters θ are optimized"
2순위
The loss L_θ^BYOL is between L2-normalized prediction q̄_θ(z) and z̄′ (DINO는 cross-entropy야. 바꿔치기 함정)
버려도 됨
y · z · q · ξ 기호 대응, L2-normalize 식, L̃ (view 바꾼 대칭 loss) 표기

DINO

L04 p.40 ★★ 나올 수도

label 없는 self-distillation: student가 EMA teacher의 출력 분포를 다른 view에서 CE로 따라가. collapse는 teacher 쪽 centering + sharpening으로 막아.

빈칸
t = softmax((t - C) / tpt, dim=1) # + sharpen인정: centering
왜
DINO만의 collapse 방지 장치야. teacher 쪽에만 걸려 (student는 softmax(s / tps)만). 원본 그림(누르면 열림) 왼쪽 도식에서도 centering 박스는 teacher 위에만 있어.
어느 방법?
gs, gt: student and teacher networks, loss = H(t1, s2)/2 + H(t2, s1)/2 (view 교차), gt.params = l*gt.params + (1-l)*gs.params (teacher ← student의 EMA)
2순위
t = t.() # stop gradient (teacher 쪽 gradient 차단. MoCo · X-CLR와 같은 단어)
2순위
gt.params = l*gt.params + (1-l)*.params (teacher ← student의 EMA. student ↔ teacher 바꿔치기 함정)
버려도 됨
tps / tpt, l / m 기호, center 갱신식 C = m*C + …, .sum(dim=1).mean(), /2 계수

MoCo Alg.1

L05 p.12 ★★★ 꼭 나온다

key encoder를 query encoder의 momentum(EMA)으로 천천히 바꾸고, 지난 batch들의 key를 FIFO queue에 쌓아 negative로 써 → 크고(large) 일관된(consistent) dictionary.

빈칸
# update: key network → f_k.params = m*f_k.params+(1-m)*f_q.params인정: momentum (EMA)
왜
방법 이름이 Momentum Contrast야. 교수님 박스: "Update f_k through momentum". key encoder는 backprop이 아니라 이 줄로만 바뀌어.
어느 방법?
k = k.detach(), l_neg = mm(q.view(N,C), queue.view(C,K)), labels = zeros(N) # positives are the 0-th, enqueue / dequeue
2순위
k = k.() # no gradient to keys (교수님 화살표 "No gradient through the key")
2순위
l_neg = mm(q.view(N,C), .view(C,K)) (교수님 박스 "Use the running queue of keys as the negative samples")
버려도 됨
bmm / mm / view shape, cat(dim=1), logits/t, NxK 같은 shape 주석

Assign from cluster IDs.

CLIP

L05 p.35 ★★★ 꼭 나온다

(image, caption) n쌍으로 n×n similarity 행렬을 만들고 대각선 = 정답. 이미지→텍스트, 텍스트→이미지 두 방향 CE를 평균해 (symmetric).

빈칸
# loss function
왜
loss_i(axis=0)와 loss_t(axis=1)를 평균 → 두 방향 다 맞히기. CLIP loss의 이름이야.

Π-model Alg.1

L06 p.18 ★★★ 꼭 나온다

같은 network에 같은 입력을 dropout · augmentation만 바꿔 두 번 넣고, 두 출력의 차이(MSE)를 줄여 (consistency).

빈칸
z̃ ← f_θ(g(x)) ▷ again, with different and augmentation인정: dropout (mask)
왜
두 줄이 글자로는 똑같은 이유가 이 빈칸이야. noise(dropout + augmentation)가 랜덤이라 출력이 달라져. forward 2번 = Π-model의 비용 → 다음 TE의 동기.
어느 방법?
z ← f_θ(g(x))와 z̃ ← f_θ(g(x)) 두 줄이 연달아, w(t)·Σ‖z − z̃‖²
2순위
+ w(t)·1/(C|B|)·Σ_{i∈B} ‖z_i − z̃_i‖² ▷ loss component (label 없는 샘플까지 B 전체에 걸려)
버려도 됨
Require 목록, 1/|B| · 1/(C|B|) 계수, ADAM, B∩L 표기

Temporal Ensembling Alg.2

L06 p.20 ★★ 나올 수도

두 번째 forward 대신 그 샘플의 과거 예측 평균(EMA)을 target으로 → forward 1번. 대신 샘플마다 예측을 저장해.

빈칸
Z ← αZ + (1−α)z ▷ accumulate ensemble 인정: ensemble predictions
왜
weight가 아니라 prediction의 EMA야. weight EMA는 Mean Teacher. 이 대비가 L06의 핵심이야.
어느 방법?
Z ← 0[N×C] (샘플별 표), forward 한 줄 z ← f_θ(g(x, t)), epoch 끝의 Z ← αZ + (1−α)z, z̃ ← Z/(1−α^t)
2순위
z̃ ← Z/(1−α^t) ▷ construct target vectors by (Z가 0에서 시작해 생긴 치우침 보정. Adam과 같은 원리)
버려도 됨
0 ≤ α < 1 범위, Algorithm 2 캡션 문장, loss 계수

DivideMix Alg.1

L07 p.54 ★★★ 꼭 나온다

per-sample loss에 GMM을 맞춰 clean(labeled) / noisy(unlabeled)로 나누고, 그 분할을 상대 network에 줘 (co-divide). 그다음은 MixMatch로 학습.

빈칸
W^(2) = (X, Y, θ^(1)) // model per-sample loss with θ^(1) to obtain clean proabability for θ^(2)인정: Gaussian Mixture Model
왜
loss가 작으면 clean, 크면 noisy. θ^(1)로 만든 분할을 θ^(2)가 써서, 자기 실수를 자기가 믿는 confirmation bias를 줄여. 교수님이 빨간 글씨 "Co-divide"를 달았고 p.53에 "Why use GMM?"도 있어.
어느 방법?
두 network θ^(1), θ^(2), GMM(·, θ^(1)) → W^(2) (교차), w_i ≥ τ → labeled set, MixMatch(X̂, Û)
2순위
L_X, L_U = (X̂, Û) // apply MixMatch (DivideMix는 새 학습 알고리즘이 아니라 MixMatch에 넣을 데이터를 나누는 방법이야)
버려도 됨
line 7–8 집합 식, line 17–21 수식 (co-refinement · co-guessing 식), Sharpen T, λ_u, WarmUp
