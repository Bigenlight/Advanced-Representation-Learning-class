  • 8-1-3Transfer learningauxiliary categories(box 있음)로 detector 학습 → weakly supervised categories로 지식 이전

Object detectionL08 p.4 · p.14
사진 안에서 어떤 물체가 어디 있는지 찾는 task야. 출력은 물체마다 class 이름과 위치(box)야.

예사진 한 장에서 "motorbike는 이 box, person은 저 box"라고 내놓는 거야. 분류(classification)는 사진 전체에 "motorbike"라고만 답해.

왜이 강의의 주인공인 WSOD(Weakly-Supervised Object Detection)는 test 때 detection을 해야 하는데, train 때는 위치를 안 줘.

로봇 policy 앞단의 perception이야. 어느 물체가 어디 있는지가 policy의 observation이 돼.
Bounding box (b-box)L08 p.4–5
물체를 감싸는 직사각형이야. 좌표 네 개로 표현해.

예오토바이 주위에 그린 빨간 사각형. 슬라이드 기준으로 box 하나에 10 sec per instance가 들어 (p.4).

왜일반적인 detection의 정답(label)이 box야. WSOD는 이 box label을 안 쓰는 설정이야.

object-centric state에서 물체 하나의 위치를 나타내는 좌표 묶음이라고 보면 돼.
Fine-tuningL08 p.8
이미 학습된(pretrained) network의 weight를 시작점으로 삼아서 새 task의 data로 이어서 학습하는 거야.

예분류로 학습한 CNN을 가져와서 image label로 detection용으로 더 학습시켜.

왜weakly supervised learning은 "Typically uses pretrained networks and fine-tunes them by using weak supervision" (p.8).

offline pre-training 뒤 online fine-tuning과 같은 구도야.

MIL(Multiple-Instance Learning) 부품

BagL08 p.15
instance 여러 개를 담은 묶음이야. label은 묶음 전체에만 붙어. WSOD에선 사진 한 장이 bag이야.

예motorbike가 있는 사진은 positive bag, 없는 사진은 negative bag이야.

왜image label을 "bag label"로 보면 WSOD가 bag classification 문제가 돼 (p.15).

episode 하나에 성공/실패만 있고 어느 timestep이 잘했는지 모르는 상황이랑 닮았어(credit assignment). 단 MIL은 "적어도 하나"이고 return은 합이라서 같진 않아.
InstanceL08 p.15
bag 안의 낱개 하나야. WSOD에선 후보 window 하나가 instance야. 이 강의엔 뜻이 하나 더 있어: 사진 속 물체 한 개도 instance라고 불러 ("per instance" p.4, "multiple positive instances" p.35).

예사진 한 장에 후보 box가 2,000개면 instance가 2,000개야. 그중 어느 게 진짜 물체인지는 안 알려 줘.

왜"only the bag label (not the instance labels) is known" (p.15). 이 빠진 정보를 찾는 게 WSOD의 일이야.

episode 안의 timestep 하나에 해당해.
Proposal · windowL08 p.17
물체가 있을 수 있는 후보 사각형이야. 슬라이드는 window, proposal, region을 거의 같은 뜻으로 써.

예Selective Search나 Edge Boxes가 사진 한 장에서 약 2k개의 proposal을 뽑아 (p.17).

왜모든 위치를 다 보지 않고 후보 안에서만 고르면 되니까 문제가 "이 중 뭐가 물체야?"로 줄어.

전체 action space 대신 candidate action 집합을 먼저 뽑고 그 위에서 argmax 하는 것과 비슷해.

WSOD 부품

IoU슬라이드 밖 기초 · L08 p.37 "surrounding"
Intersection over Union. 두 box가 얼마나 겹치는지 나타내는 값이야. 겹친 넓이 ÷ 합친 넓이라서 0(안 겹침)부터 1(완전히 같음)까지야.

예설명용: 넓이 10인 box 두 개가 넓이 5만큼 겹치면 IoU = 5 / 15 ≈ 0.33이야.

왜슬라이드의 "surrounding ones"(최고 proposal 주변 box)를 코드로 쓰면 보통 IoU 기준이 돼.

goal-conditioned RL의 "목표에서 ε 안이면 성공" 같은 판정 기준 역할이야.
RoI poolingL08 p.34
RoI(Region of Interest, 관심 영역)마다 크기가 다른 영역을 같은 크기의 feature로 바꾸는 층이야.

예큰 box든 작은 box든 feature map에서 해당 자리를 잘라 같은 크기로 만들어 다음 층에 넣어.

왜사진 전체를 Conv layers에 한 번만 통과시키고, proposal 수천 개가 그 결과를 같이 써. proposal별 점수에서 Conv layers까지 gradient가 이어져서 network 전체를 같이 학습할 수 있어 (WSDDN). ← slide는 RoI-Pooling이라고 적었는데, 논문은 SPP(spatial pyramid pooling)라고 불러. 시험은 슬라이드 표기로 봐.

actor와 critic이 encoder 하나를 공유해서 계산을 재사용하는 것과 같은 발상이야.
Discriminative partL08 p.35 · p.38 · L09 p.28
물체 중에서 class를 구별하기에 제일 쉬운 일부분이야. discriminative = 구별력이 있는.

예사람의 얼굴, 고양이의 머리. box가 물체 전체가 아니라 여기만 잡는 게 WSOD의 대표 실패야 (p.35).

왜image label을 맞히는 데는 그 부위만 봐도 충분해서, loss가 물체 전체를 볼 이유를 안 줘.

L09CAM도 같은 문제를 겪어: "Focused on discriminative area only" (L09 p.28). Hide-and-Seek과 adversarial erasing이 이걸 직접 공격해 (L09 p.37–41).

쉽게 점수를 얻는 shortcut만 배우는 것과 닮았어. 일부러 속이는 건 아니고, loss가 그걸로 충분하니까 생기는 일이야.
ObjectnessL08 p.28
window 안에 class에 상관없이 뭔가 물체가 있을 가능성을 숫자로 매긴 거야. "Quantify how likely a window is to contain an object of any class" (p.28).

예오토바이를 감싼 box는 높고, 하늘만 담긴 box는 낮아.

왜class와 무관한 prior라서 box label 없이도 쓸 수 있고, 배경이나 부품 대신 whole object 쪽으로 밀어 줘.

점수에 task-agnostic prior를 섞는 것과 비슷해. 단 potential-based reward shaping은 아니야.
CRFL08 p.25 · L09 p.31
Conditional Random Field. 여러 node의 상태를 한꺼번에 고르는 그래프 모델이야. node 혼자의 점수(unary)와 이어진 두 node의 점수(pairwise)를 같이 봐.

예p.25에선 node = 사진, 상태 = 고른 window, unary = objectness score, pairwise = window끼리의 similarity야.

왜사진마다 따로 고르지 않고 "서로 닮은 window"를 동시에 고르려면 이런 틀이 필요해.

L09SEC의 Constrain-to-boundary loss도 CRF를 써: "Refine predictions using CRF" (L09 p.31). 거기선 node = pixel이고, 가깝고 색이 비슷한 pixel끼리 같은 label을 주려는 모양이야 (보충). L08 p.25의 CRF(node = 사진)와 이름만 같고 그래프가 달라.

multi-agent RL의 coordination graph(개별 utility + 짝 utility)와 같은 모양이야.

Segmentation 기초 (L09)

Semantic segmentationL09 p.4 · p.19
사진의 모든 pixel마다 class를 붙이는 task야. 같은 class의 물체가 두 개 있어도 구분하지 않아 (둘 다 "person").

예사람 · 고양이 · 문이 있는 사진(p.11)이면 출력은 사진 크기의 지도이고, 칸마다 person / cat / door / background 중 하나가 적혀.

왜L09의 주인공 WSSS(Weakly-Supervised Semantic Segmentation)는 test 때 이 pixel 지도를 내야 하는데, train 때는 image label만 줘 (p.19).

manipulation에서 pixel마다 "여길 잡으면 성공할까"를 내는 affordance map과 같은 dense 출력이야.
Instance segmentationL09 p.54 · p.95
물체를 하나하나 따로 구분하는 segmentation이야. 사람이 두 명이면 mask도 두 개가 나와.

예"From box-level labels to pixel-level instance labels" (p.54)는 box마다 그 물체의 mask를 만드는 문제야. WISH(p.86–95)도 instance segmentation이야 ("Conventional WSIS", p.95).

왜semantic은 "무슨 class냐"만 묻고, instance는 "몇 번째 물체냐"까지 물어. 둘을 바꿔 쓴 지문을 조심해.

object-centric state에서 물체마다 slot을 따로 두는 것과 같아.
Pixel-level labelL09 p.19
pixel마다 정답 class를 단 label이야. 정답 mask라고도 해. label 중에 제일 비싸.

예L08 p.4 기준으로 pixel labels는 78 sec per instance라서 b-box(10 sec)의 약 8배야.

왜WSSS는 "Image-level labels at training time"으로 "Pixel-level labels at test time"을 내야 해 (p.19). 이 차이를 메우는 게 강의 전체의 일이야.

image label이 episode 끝의 sparse reward라면, pixel label은 매 step의 dense reward야.
mIoUL09 p.41 · p.73
mean Intersection over Union. class마다 예측 mask와 정답 mask의 IoU(겹친 넓이 ÷ 합친 넓이)를 구해서 평균 낸 segmentation 점수야. 보통 0–100(%)으로 적어.

예CD-CLIP: "CDA significantly improves the CAM mIoU from 70.1 to 80.3" (p.73). 수치 자체는 시험 비중이 낮아.

왜슬라이드의 결과표가 대부분 이 숫자로 방법을 비교해. 숫자가 크면 mask가 정답과 더 많이 겹친다는 뜻이야.

여러 task의 success rate를 평균 낸 점수처럼 읽으면 돼.

CAM 부품 (L09)

Saliency mapL09 p.8 · p.21–22 · p.34
"어느 pixel이 중요했나"를 밝기로 그린 지도야. 이 강의엔 뜻이 두 개야. (1) classifier 점수를 입력으로 미분한 gradient 지도 (gray box, p.21–22). (2) class와 상관없이 눈에 띄는 물체(foreground)를 찾는 saliency model의 출력 (prior p.8, Oh p.34).

예(1)은 "salt-and-pepper"처럼 점이 흩어져 (p.21). (2)는 물체 전체 범위를 덮지만 무슨 class인지는 몰라 (p.34).

왜같은 단어라서 T/F에서 헷갈려. gradient saliency의 함정은 noisy, Oh의 saliency의 함정은 class-agnostic이야.

Atari agent가 화면의 어디를 보고 움직였는지 그리는 saliency map이 (1)과 같은 도구야.
GAPL09 p.24
Global Average Pooling. feature map 한 장(채널 하나)을 모든 위치에 대해 평균 내서 숫자 하나로 만드는 층이야.

예설명용: 채널이 512개면 GAP 뒤엔 위치 정보 없이 숫자 512개가 남아.

왜CAM은 FC layer를 빼고 GAP을 넣어 (p.24). 그러면 class 점수 = class weight × (map의 평균)이 되니까, 평균 내기 전의 map에 같은 weight를 곱하면 위치 지도가 나와.

image encoder 끝에서 spatial feature를 pooling해 벡터로 만든 뒤 MLP policy에 넣는 것과 같아.
CAML09 p.24–26
Class Activation Mapping. class 하나에 대해 "사진의 어디가 그 class 같았나"를 보여 주는 지도야. 마지막 conv feature map들을 그 class의 weight로 더해서 만들어: Mc(x,y) = Σk wkc fk(x,y) (식은 논문, 슬라이드 p.25엔 같은 내용이 그림으로 있어).

예p.26은 한 사진에서 예측한 class마다 CAM을 따로 그려 ("Designed to Generate Per-Class Maps"). 같은 사진도 class가 다르면 밝은 곳이 달라.

왜"activation maps can be obtained directly without the need for separate gradient calculations" (p.25). 이 지도를 threshold로 자른 seed가 WSSS의 출발점이야.

pooled feature 위에 linear head가 있는 policy라면, action logit의 weight로 feature map을 더해서 "이 action을 고를 때 어디를 봤나" 지도를 같은 식으로 얻을 수 있어.
SeedL09 p.27
CAM을 threshold로 잘라서 얻은 확실한 영역이야. "High value scores ➝ Foreground areas", "Low value scores ➝ Background areas", "(This confident regions are commonly named "seeds")" (p.27).

예설명용: CAM 값이 0.8인 pixel은 foreground seed, 0.05인 pixel은 background seed가 돼. 0.4처럼 애매한 pixel은 label을 안 주는 걸로 읽으면 돼 (해석).

왜seed가 segmentation network의 첫 학습 data(pseudo label)가 돼. SEC의 Seeding loss가 바로 이 seed를 지켜 (p.31).

confidence가 높은 target만 골라 쓰는 filtering이야. FixMatch의 threshold와 같은 발상이야.
Pseudo maskL09 p.34 · p.56
사람이 아니라 모델이나 규칙이 만든 "가짜 정답 mask"야. pseudo label의 segmentation 버전이야.

예Oh: "Combine CAM and saliency to generate class-specific pseudo masks" (p.34). Khoreva: "the CNN's predictions are then used as pseudo-labels for retraining" (p.56).

왜WSSS 방법 대부분은 결국 pseudo mask를 만들고 그걸로 segmentation network를 학습해. 그래서 "pseudo mask를 누가 어떻게 만드나"가 방법을 가르는 기준이야.

자기 추정으로 만든 TD target(bootstrapped target)과 같아. 틀린 target이 쌓이면 confirmation bias가 생기는 것도 같아.
AffinityL09 p.36 · p.64–69
두 pixel(또는 patch)이 "같은 물체에 속할 것 같은 정도"를 숫자로 나타낸 거야. 보통 feature나 attention의 유사도로 계산해.

예SEAM의 PCM은 "pixel-wise affinity among CNN features"로 CAM activation을 같은 물체의 다른 pixel로 퍼뜨려 (p.36). CD-CLIP은 이 affinity를 class distribution으로 보정해 (p.69).

왜CAM이 한 부분만 켜질 때 affinity로 이웃에 퍼뜨리면 물체 전체를 덮을 수 있어. 대신 affinity가 틀리면 "Foreground activation can cross class boundaries" (p.64).

state 유사도 graph를 따라 value를 이웃 state로 퍼뜨리는 것과 같아.
EquivarianceL09 p.35–36 · L08 p.29
입력을 변환하면 출력도 같은 방식으로 변환되는 성질이야. invariance(입력이 변해도 출력이 그대로)와 다른 개념이야.

예사진을 줄이면 CAM도 같이 줄어야 해. SEAM: "Activation maps should be equivariant to the input" (p.35).

왜사진을 조금 변환했을 뿐인데 CAM이 다르게 나오면("Small input transformations can produce different activation maps", p.36) 그 차이 자체가 label 없는 학습 신호가 돼. L08 p.29의 equivariance prior와 같은 개념이야.

물체를 돌려 놓으면 grasp도 같이 돌아가야 한다는 SE(2) equivariant policy와 같은 성질이야.
Hiding · ErasingL09 p.37–41
학습할 때 사진의 일부를 가리거나 지워서 network가 다른 부분도 보게 만드는 방법이야.

예Hide-and-Seek은 patch를 random으로 가려 (p.37). Adversarial erasing은 지금 classifier가 제일 크게 반응하는 영역을 골라서 지우고 다시 학습해 (p.39).

왜CAM은 "activates only the most discriminative regions" (p.37). 그 부분이 안 보이면 classifier가 다른 부분으로 맞혀야 해서 CAM이 넓어져.

occlusion augmentation으로 policy가 단서 하나에만 기대지 않게 하는 것과 같아. adversarial erasing은 "정책이 제일 의존하는 단서를 일부러 가리고 다시 학습하는" 것과 비슷해. min-max 학습은 아니야 (min-max는 L08 Concrete DropBlock).

Web · Box · 이어서 배우기 (L09)

Webly supervisedL09 p.44
웹 검색으로 모은 사진과 그 검색어를 supervision으로 쓰는 거야. "A learning method that uses data collected from the web as supervision" (p.44).

예"dog"로 검색해서 받은 사진에 "dog" label을 붙여 써. 공짜지만 "Labels are noisy, ambiguous, and incomplete" (p.44).

왜"trading annotation cost for label noise" (p.44). Shen은 웹 사진이 "typically containing a single centered object"라서 mask를 자동으로 만들기 쉽다는 점을 이용해 (p.47).

인터넷의 사람 영상으로 robot representation을 pretraining하는 것과 같은 거래야. 공짜 data를 얻는 대신 noise와 domain gap을 감수해.
GrabCutL09 p.58–60 · 슬라이드 밖 기초
box 하나를 주면 그 안에서 물체(foreground)와 배경을 색 분포와 graph cut으로 나누는 고전 segmentation 알고리즘이야. 학습하는 network가 아니야.

예Khoreva는 box를 꽉 채운 rectangle 대신 GrabCut+로 만든 mask에서 학습을 시작해. "We reach ~95% of full supervision by using GrabCut++" (p.60) ← 그래프 범례엔 "Grabcut+"로 적혀 있어.

왜시작 mask가 좋을수록 recursive training이 더 높은 곳에서 출발해 (p.58–59).

scripted policy로 만든 시연으로 학습을 시작하는 것과 비슷해. 학습 없는 prior가 좋은 초기값을 줘.
Incremental learningL09 p.77–79
학습을 한 번에 끝내지 않고, 단계(step)마다 새 class를 추가로 배우는 설정이야. continual learning이라고도 해.

예Liu: step t에 새 class(예: dog, sofa)가 들어오는데 "Original training images are no longer accessible" (p.77). 결과표의 10–10 · 15–5 · 10–1이 이런 단계 설정의 이름이야 (p.84–85).

왜새 class를 배우면 옛 class를 잊어. 그래서 rehearsal이 필요해 (p.78).

task가 차례로 바뀌는 continual RL과 같은 설정이야.
Forgetting (catastrophic forgetting)L09 p.78
새 data로 학습하는 동안 옛 data에서 배운 걸 잊어버리는 현상이야. 슬라이드는 그냥 "forgetting"이라고 써.

예Liu의 세 번째 challenge: "Learning new classes causes forgetting of old classes" (p.78).

왜옛 사진이 없으니 옛 class를 다시 볼 방법이 필요해. "The web must provide both new knowledge and memory of old knowledge" (p.78).

multi-task RL에서 새 task를 배우다가 옛 task 성능이 무너지는 것과 같아.
RehearsalL09 p.79–83
새 걸 배우면서 옛 data를 섞어 다시 보여 주는 복습이야.

예보통은 옛 사진을 저장해 두고 섞어. Liu는 사진 대신 caption을 저장하고 웹에서 비슷한 사진을 다시 찾아 복습해: "Old image → Stored caption q' → Web search → Rehearsal image" (p.82).

왜"Store Captions, Not Images" (p.82). 원래 사진을 저장할 수 없는 설정에서도 옛 class를 복습할 수 있어.

experience replay buffer와 같은 역할이야. Liu는 transition 대신 "검색어"만 저장해 두는 replay인 셈이야.

JS divergenceL09 p.65 · p.69

↑ 요약

질문box label이 없는데 instance-level target은 어디서 오나?

L06–L07 semi-supervised learning에선 어떤 사진엔 label이 있고, 어떤 사진엔 label이 아예 없었어. 이번엔 상황이 달라. 모든 사진에 label이 있는데, 내야 할 출력보다 약해. "이 사진에 오토바이가 있다"만 알려 주고, test 때는 오토바이의 box를 내라는 거야.

이 강의의 주제는 WSOD(Weakly-Supervised Object Detection)야. 어느 후보 box가 진짜 물체인지 아무도 안 알려 주니까, 대개 모델이 고른 box가 다음 학습의 target이 돼. WSDDN처럼 box를 안 고르고 image label만으로 학습하는 예외도 있어. 그래서 흐름이 이렇게 가: 문제를 MIL로 다시 쓰고 → 고르기와 학습을 번갈아 돌리고 → 틀린 box에 굳지 않게 보강하고 → 한 network 안에서 end-to-end(입력부터 loss까지 network 전체를 gradient로 같이 학습)로 합쳐.

Weakly-Supervised Learning: 왜 약한 label인가 (p.3–8)

Weak supervisionBearman 2016 · p.4What's the Point: Semantic Segmentation with Point Supervision (ECCV 2016)

한 줄train 때 주는 label이 test 때 내야 할 출력보다 약하고 싼 설정이야.

"Weak supervision: Lower degree (or cheaper) annotation at train time than the required output at test time" (p.4). ← slide엔 저자가 Berman으로 적혀 있는데 실제론 Bearman이야.

문제정밀한 label일수록 비싸. 슬라이드 기준으로 class 이름은 1 sec per class, point는 2.4 sec per instance, b-box는 10 sec per instance, pixel labels는 78 sec per instance야.

핵심기준은 test 출력이야. WSOD라면 test 때 box가 필요한데 train엔 class 이름만 줘. 모자란 위치 정보는 모델이 찾아야 해. 그래서 box로 학습해서 pixel labels를 내는 것도 weak supervision이야.

차이semi-supervised는 label의 양이 모자란 문제고, weak supervision은 label의 정밀도가 모자란 문제야.

Semi vs Weakly semiJeong 2019 그림 · p.5Consistency-based Semi-supervised Learning for Object Detection (NeurIPS 2019)

한 줄사진마다 어떤 label이 붙었나로 설정을 네 개로 나눠.

  • (a) Supervised: 모든 사진에 box가 있어.
  • (b) Weakly supervised: 모든 사진에 image label만 있어.
  • (c) Weakly semi-supervised: "learns from a set of labeled (bounding box) and weakly labeled (image label) images."
  • (d) Semi-supervised: "learns from a set of labeled (bounding box) and unlabeled images."

차이(c)와 (d)는 box 있는 사진은 같고 나머지 사진이 달라. (c)는 image label이 있고, (d)는 아무 label도 없어.

Transfer learningHoffman NIPS 14 그림 · p.6

한 줄box가 있는 다른 class의 지식을 box가 없는 class로 옮겨.

핵심"Learns detectors for auxiliary categories with regular supervision (bounding box)". 그리고 "Transfers the knowledge from auxiliary categories to weakly supervised categories" (p.6). auxiliary categories = 도우미로 쓰는 class야.

차이순수 weak supervision과 달리, 다른 class에는 box label이 필요해.

Self-supervised learningp.7

한 줄pretext task(label 없이 data에서 정답을 만드는 연습 문제)로 representation을 배우고 weight를 옮겨 써.

핵심"Defines a pretext task and learns representations in an unsupervised way", "Transfers pre-trained weights to a downstream task" (p.7). 그림 예시는 L02의 relative position과 rotation이야.

차이슬라이드가 짚는 건 "Transfer-learning requires regular annotations"야. pre-train엔 label이 없어도 downstream에 옮긴 뒤엔 일반 annotation이 필요해. weak supervision은 그 annotation 자체를 약하게 만드는 쪽이야.

Pretrained + weak fine-tuningp.8

한 줄보통 처음부터 학습하지 않고 pretrained network를 weak label로 fine-tuning해.

"Typically uses pretrained networks and fine-tunes them by using weak supervision" (p.8).

차이p.7 self-supervised의 fine-tune은 regular annotation을 쓰고, 여기선 weak label을 써.

Challenges: 왜 어렵나 (p.9–13)

Generic object recognitionp.10

한 줄같은 class 안에서도 생김새가 크게 달라서 물체 찾기는 원래 어려워.

  • Intra-class variations(같은 class 안의 차이): Appearance(겉모습), Viewpoint(보는 방향), Scale(크기), Aspect ratio(가로세로 비율).
  • Background clutter: 배경이 복잡해서 물체가 묻혀.
  • Occlusions: 다른 물체에 가려져.

차이슬라이드 제목이 "Generic Object Recognition"이야. 이건 물체 인식 일반의 어려움이고, 다음 카드의 co-occurrence가 image label만 있을 때의 애매함이야 (p.40).

Co-occurrencep.11–13

한 줄늘 같이 나오는 것들은 image label만으로 갈라낼 수 없어.

  • Parts vs object (p.11): What is a person? a) Face b) Face + upper body c) Face + whole body ☺
  • Context vs object (p.12): What is a train? a) Rail b) Train + Rail c) Train ☺
  • Multiple vs single instance (p.13): What is a sheep? a) 2 sheeps b) 3 sheeps + grass c) 1 sheep ☺

왜 어려워?"person" label이 붙은 사진엔 늘 얼굴이 있어. 그럼 얼굴 box만 골라도 label을 맞힐 수 있어서, 무엇이 "person 전체"인지 알 근거가 없어. 그래서 p.40은 "WSOD is an ill-posed problem and ambiguous due to part/whole and co-occurence issues"라고 정리해. ill-posed = 주어진 정보만으론 답이 하나로 안 정해지는 문제야.

차이세 경우 모두 정답은 물체 하나 전체야. 오답은 그보다 작거나(부품), 크거나(배경까지 포함 · 여러 마리를 같이 묶음), 물체가 아닌 곳(Rail)이야.

WSOD의 기본 틀: Multiple-Instance Learning (p.14–21)

MILp.15Multiple-Instance Learning

한 줄사진을 후보 box들의 묶음으로 보고, 묶음 전체의 label만으로 학습하는 틀이야.

"MIL reformulates weakly supervised object detection as a bag classification problem, where each image is a bag of candidate windows, and only the bag label (not the instance labels) is known." (p.15)

핵심bags = images, instances = windows. Goals는 두 개야: find true positive instances, train window classifier.

왜 돼?MIL의 표준 가정 때문이야(슬라이드 문장은 아니야). positive bag엔 positive instance가 적어도 하나 있고, negative bag의 instance는 전부 negative야. 그래서 negative 사진이 "이건 물체가 아니야"를 공짜로 알려 줘.

차이일반 분류는 샘플마다 label이 있어. MIL은 묶음마다 label이 있고 낱개 label은 몰라.

Standard MIL pipelinep.16 · 19 · 32

한 줄고른 box로 detector를 학습하고, 그 detector로 box를 다시 고르는 걸 반복해.

어떻게"Two step alternating optimization" (p.16).

  1. Initialize: 사진마다 첫 box를 잡아.
  2. Re-train: 지금 box로 detector를 학습해.
  3. Re-localize: 학습한 detector로 box를 다시 골라.
  4. 2–3을 반복해.

문제Challenges는 두 개야. "Sensitive to initialization (local minimum)", "Overfitting (locking) to predicted windows" (p.16). locking = 틀린 box로 학습하면 그 box 점수가 올라서 같은 box가 계속 뽑히는 악순환이야 (p.23). 이 강의의 나머지는 대부분 이 두 문제를 푸는 얘기야.

차이L07 self-training과 같은 구조야. 자기 예측이 다음 target이 되고, locking은 confirmation bias(틀린 자기 예측을 스스로 강화하는 것)와 같은 모양이야. 다른 점은 고르는 대상이 class가 아니라 box라는 거야.

How to generate bagsFerrari slide · p.17

한 줄bag 안의 window를 sliding window나 object proposal로 만들어.

  • Sliding windows: >100, dense, "translations, scales and aspect-ratios (4D space)". 4D = 가로 위치, 세로 위치, 크기, 가로세로 비율이야. ← slide의 ">100"은 "dense"하고도, proposal "~2k"하고도 안 맞아. 숫자가 잘렸을 수 있지만 실제 값은 몰라. 시험은 슬라이드 표기로 봐.
  • Object proposals: Selective Search and Edge Boxes, ~2k per image, "Commonly used in WSOD".

차이sliding window는 규칙적으로 전부 훑고, proposal은 물체처럼 보이는 자리만 골라 둬.

InitializationSong 2014 · p.18On Learning to Localize Objects with Minimal Supervision (ICML 2014)

한 줄첫 box를 어떻게 잡나. 쉬운 방법은 사진 전체, 좋은 방법은 사진끼리 비교하기야.

문제pipeline이 initialization에 민감해서 시작점이 나쁘면 local minimum에 빠져.

어떻게Simple strategies는 Whole image, Whole image minus a margin이야. Song은 "constructs a graph to find initial boxes"라서 세 조건으로 box를 골라.

  1. relevant: occur in many positive images
  2. discriminative: dissimilar to the boxes in the negative images
  3. complementary: capture multiple modes

차이Simple은 사진 한 장만 보고 정해. Song은 positive 사진들과 negative 사진들을 서로 비교해서 정해.

Re-localizeNguyen 09 외 · p.20

한 줄지금 detector가 제일 높게 매긴 window 하나를 positive로 골라.

arg maxb A(xb)

b = proposal, A = appearance model(window 점수를 내는 모델), xb = 그 proposal의 features야. "Pick the highest scoring window as positive", "Only one positive instance per image" (p.20).

차이Re-localize는 detector를 고정하고 box를 바꿔. Re-train은 box를 고정하고 detector를 바꿔.

Re-trainNguyen 09 외 · p.21

한 줄고른 window는 positive로, negative 사진의 window는 전부 negative로 detector를 학습해.

핵심"Hinge and cross-entropy loss" (p.21). 왼쪽이 hinge 조건, 오른쪽이 cross-entropy 쪽 항이야. hinge = 점수가 margin을 넘으면 loss 0, 못 넘으면 모자란 만큼 벌점을 주는 loss야. margin(Δ) = 간신히 맞히는 걸로 안 치고 이만큼 넘으라는 여유 폭이야.

For positive images: maxb A(xb) > Δ (Δ: margin) or log(Softmax(maxb A(xb)))

For negative images: maxb A(xb) < −Δ or log(1−Softmax(maxb A(xb)))

← slide의 log 항은 키워야 할 목적식이야. loss로 쓰려면 부호를 뒤집어. Softmax 인자도 하나만 적혀 있어.

왜 돼?두 줄 다 max인 게 포인트야. positive 사진은 제일 높은 window가 Δ를 넘으면 "적어도 하나 있다"가 돼. negative 사진은 제일 높은 window마저 −Δ 아래면 모든 window가 −Δ 아래가 돼. max 하나로 "전부 negative"까지 표현한 거야.

차이supervised detection(eg Faster-RCNN, box label로 학습하는 대표 detector)과 다른 점은 둘이야. "Only 1 positive instance is used in each positive image", "No negative instances from positive image" (p.21). 이 목록은 WSDDN 한계로 p.35에 또 나와.

MIL 보강 1: 틀린 box에 굳지 않게 (p.22–26)

Relaxing max operatorBilen 2014 · p.22Weakly Supervised Detection with Posterior Regularization (BMVC 2014)

한 줄window 하나에 다 걸지 말고 점수 높은 여러 window에 나눠 걸어 ("Hedge your bets on multiple proposals").

문제hard max는 window 하나만 고르니까 그 선택이 틀리면 그대로 굳어. 그리고 positive를 하나밖에 못 써.

핵심"Relax hard max into soft-max (log-sum-exp)" (p.22). Re-train 조건에서 max를 log-sum-exp로 바꿔. 여기서 soft-max는 값 하나를 내는 부드러운 max야. p.21의 Softmax처럼 확률을 내는 함수와 이름만 같아.

For positive images: log Σb exp A(xb+) > Δ

For negative images: log Σb exp A(xb−) < −Δ

xb+ = positive 사진의 window feature, xb− = negative 사진의 window feature야.

왜 돼?슬라이드엔 결과 식만 있어서 아래는 보충이야. window가 B개면 max ≤ LSE ≤ max + log B라서 log-sum-exp(LSE)는 max의 부드러운 버전이야. 미분하면 ∂LSE/∂Ab = softmax(A)b라서 gradient가 eA 비율(softmax 비중)대로 나뉘어. 점수 자체의 비율이 아니야.

예시로 보면

설명용 점수 A = [3, 2.9, −1]. hard max의 gradient는 [1, 0, 0]이라 2.9짜리 window는 아무 신호도 못 받아. LSE의 gradient는 [0.52, 0.47, 0.01]이라 비슷한 두 window가 둘 다 배워. LSE 값은 3.65로 max 3과 상한 4.10 사이야.

차이결과는 "Less sensitive to initialization", "Leverages multiple positive samples during training"이야. max는 window 하나, soft-max는 window 여러 개를 살려.

Self-paced learningSangineto · p.23Self Paced Deep Learning for Weakly Supervised Object Detection (TPAMI 2019) ← slide엔 PAMI 17

한 줄쉬운 샘플부터 학습하고, localization이 믿을 만해지면 어려운 샘플을 늘려.

문제"In conventional WSOD, the initial localization results are crucial." 처음에 틀린 box를 고르면 detector가 그 box로 학습되고, 같은 box가 또 뽑히는 vicious cycle(locking)이 돼 (p.23).

핵심"Inspired from Curriculum Learning". 어려운 샘플까지 처음부터 다 쓰지 말고, "train progressively, beginning with easy samples".

어떻게Easiness measures for WSOD는 세 개야.

  1. Selection of samples via confidence of max scoring window
  2. Selection of window space by allowing smaller windows
  3. Selection of samples via intercategory competition

차이Relaxing max는 window를 고르는 방식을 바꾸고, self-paced는 샘플을 쓰는 순서를 바꿔. L07 FreeMatch의 올라가는 threshold도 같은 curriculum 계열이야.

Multifold MILCinbis 2017 · p.24Weakly Supervised Object Localization with Multi-fold Multiple Instance Learning (TPAMI 2017) ← slide 크레딧엔 Sangineto PAMI 17

한 줄어떤 사진의 box는 그 사진으로 학습하지 않은 detector가 골라.

문제"Detector overfits into the given proposal". 자기가 학습한 box엔 점수가 높게 나와서 그 box를 또 고르게 돼.

핵심"the detector performing localization for an image must be one that has not been trained on that image." cross-validation처럼 해 (p.24).

어떻게"Train using positive examples in all folds but k, and all negative examples".

  1. positive 사진을 K개 fold로 나눠.
  2. fold k를 뺀 positive + negative 전부로 detector를 학습해.
  3. 그 detector로 fold k의 사진만 re-localize 해.
  4. k를 바꿔 가며 반복해.

왜 돼?처음 보는 사진에 매긴 점수라서 외운 box에 끌려가지 않아.

차이나누는 건 positive뿐이고 negative는 전부 써. 다른 모델의 판단을 빌린다는 점은 L07 DivideMix의 co-divide(상대 network의 분할을 쓰기)와 닮았어.

Pairwise similarityChum 07 · Deselaers 10 · Siva 11 · Bilen 15 · p.25

한 줄사진마다 따로 고르지 말고 positive 사진들 사이에서 서로 닮은 window를 같이 골라.

핵심"Similarity between selected windows across positive images". 같은 class면 고른 box끼리도 닮아야 한다는 거야. 이걸 CRF로 풀어.

문제장점은 "Less overfitting"이야. 단점은 둘이야.

  • Expensive to optimize: All positive images must be connected (N² similarities).
  • Ignores intra-class variation: "The assumption that all objects must be similar is unrealistic."

차이앞의 방법들은 사진 한 장씩 box를 고르는데, 이건 모든 positive 사진의 box를 한꺼번에 골라.

Sub-categories · ExemplarsWang 2014 · Chum 07 · Bilen 2015 · p.26Weakly Supervised Object Localization with Latent Category Learning (ECCV 2014)Weakly Supervised Object Detection with Convex Clustering (CVPR 2015)

  • Contrastive: select a ROI that is outstanding from its context. 주변에서 튀는 ROI를 골라.

차이additive는 context가 ROI를 뒷받침하고, contrastive는 ROI가 context와 달라야 해. L03의 contrastive learning과는 이름만 같아.

한 줄class와 상관없이 "물체처럼 생겼나" 점수를 box 고를 때 같이 봐.

Deep and End-to-End WSOD (p.33–39)

지금까진 CNN을 feature 뽑는 도구로만 쓰고 그 바깥에서 고르기와 학습을 번갈아 돌렸어. 이제 그 과정을 network 안으로 옮겨. 네 방법은 한계 하나를 고치면 다음 한계가 보이는 순서로 이어져.

WSDDNBilen & Vedaldi 2016 · p.34–35Weakly Supervised Deep Detection NetworkWeakly Supervised Deep Detection Networks (CVPR 2016)

한 줄proposal마다 "무슨 class인가"와 "이 class엔 어느 proposal인가"를 따로 매겨 곱하고, 합친 값을 image label로 학습해.

문제"Previous work uses CNN as black-box feature extractor" (p.34).

핵심"First end-to-end WSOD method, finetunes a pre-trained deep network". RoI-Pooling을 쓰고, Two stream architecture야.

  1. Conv layers로 feature map을 뽑고, RoI-Pooling으로 proposal별 feature를 만들어.
  2. Classification stream: "Associates each region with a class score". region 하나 안에서 class끼리 비교해.
  3. Localization stream: "Compares regions for each class". class 하나 안에서 region끼리 비교해.
  4. 두 점수를 곱해서 proposal 점수를 만들고, proposal을 합쳐 image-level 점수를 만들어.

식슬라이드엔 식이 없고 p.36 그림에 구조만 있어(논문 보충). σclass = class 방향 softmax, σdet = region 방향 softmax, xR = σclass(xc) ⊙ σdet(xd), yc = Σr xRcr. xc, xd = 두 stream의 fc layer가 낸 점수표, xR = region별 최종 점수, yc = class c의 image-level 점수, ⊙ = 칸끼리 곱하기야. loss는 class마다 binary log-loss를 더한 거야. image 단계에선 softmax를 안 써. 한 사진에 class가 여럿일 수 있어서야.

왜 돼?yc를 키우려면 class c에 맞는 proposal의 곱이 커져야 해. 그래서 image label만 줘도 proposal별 점수가 저절로 생겨. p.36은 이걸 "implicit instance scoring"이라고 불러.

결과(+) State-of-the-art results with VGG-F (~AlexNet) (62% of supervised). (+) End-to-end learning + No custom deep learning layers. (−) Detects discriminative parts rather than whole object extent. (−) Groups multiple instances together.

문제Limitations (compared to the supervised case, eg Faster RCNN)는 세 개야 (p.35). 뒤의 방법들이 이걸 하나씩 다뤄. 어느 방법이 어느 한계를 다루나는 이 파트 끝의 비교표에 있어.

  • It does not leverage multiple positive instances in positive images
  • It does not exploit negative instances in positive images
  • It does not learn bounding box regression. bounding box regression = 고른 proposal의 좌표를 조금씩 고쳐서 물체에 더 딱 맞는 box로 만드는 학습이야(슬라이드 밖 기초). 이게 없으면 proposal 모양을 그대로 써.

차이classical MIL은 고르기와 학습을 번갈아 돌리고, WSDDN은 network 하나를 end-to-end로 학습해. 앞의 두 limitation은 Re-train의 p.21 목록과 같아.

OICRTang 2017 · p.36Online Instance Classifier RefinementMultiple Instance Detection Network with Online Instance Classifier Refinement (CVPR 2017)

한 줄WSDDN 점수로 proposal에 pseudo label(L07처럼 사람이 아니라 모델이 만든 가짜 정답)을 달고, 그걸로 instance classifier를 학습하는 단계를 여러 번 쌓아.

문제"WSDDN learns to classify images based on implicit instance scoring". 학습 목표가 사진 분류라서 instance 분류는 간접적이야.

핵심"OICR learns to classify instances". "Initially uses WSDDN to set instance labels", "Iteratively refines them by using an instance classifier" (p.36).

WSDDN → Pseudo labels → Instance classifier → Better pseudo labels → Better instance classifier → ..

  1. WSDDN 구조가 proposal scores를 내.
  2. 앞 단계 점수로 highest scoring proposal과 surrounding ones를 positive로 잡아 (p.37). 이걸 사진에 있는 class마다 하고, 나머지 proposal은 background label로 둬(둘 다 논문 보충. 슬라이드엔 그림에 Supervision 화살표만 있어).
  3. 다음 단계의 Fc layer + Softmax over classes가 이 label을 맞히게 학습해.
  4. 그 단계의 점수로 또 다음 단계의 pseudo label을 만들어. 1-st부터 K-th까지 이어져.

왜 돼?단계가 뒤로 갈수록 target이 조금씩 나아져서 좋은 classifier가 더 좋은 pseudo label을 만들어.

차이WSDDN은 사진을 분류해서 간접적으로 배우고, OICR은 instance를 직접 분류해. L07 pseudo labeling을 instance 단위로, 한 network 안에서 online으로 하는 거야. Noisy Student처럼 모델을 다시 학습하는 반복이 아니야.

PCLTang · p.37Proposal Cluster LearningPCL: Proposal Cluster Learning for Weakly Supervised Object Detection (TPAMI 2020) ← slide엔 PAMI 18

한 줄점수 높은 proposal을 cluster로 묶고, cluster 하나를 pseudo object(모델이 "여기 물체 하나가 있다"고 치는 단위) 하나로 써.

문제"Observation: There can be multiple positive instances in an image". 그런데 "OICR considers only the highest scoring proposal + surrounding ones as positives". 즉 "OICR uses a single pseudo object per image"야.

어떻게edge를 잇는 기준은 슬라이드에 없어.

  1. "builds an undirected graph of top-ranking proposals"
  2. "iteratively selects vertices which have most connections to be the cluster centres"
  3. cluster 하나를 독립된 pseudo object로 삼아 instance-level supervision을 줘.

차이OICR은 pseudo object가 사진당 하나(논문은 class마다 하나, 같은 class 물체가 둘이어도 하나만 잡아)야. PCL은 cluster 하나가 pseudo object 하나라서 사진당 여러 개가 될 수 있어. 그래서 multiple positive instances를 쓸 수 있어.

Instance-aware, Context-focused WSODRen 2020 · p.38–39Instance-aware, Context-focused, and Memory-efficient Weakly Supervised Object Detection (CVPR 2020)

한 줄제일 눈에 띄는 부위를 일부러 가려서 detector가 물체 전체를 보게 만들어.

문제discriminative part 문제야. "Unlike OICR and PCL that mainly improve pseudo-label quality, this work explicitly addresses the discriminative-part problem." (p.38)

핵심"Builds on WSDDN and OICR". 세 가지를 더해.

  • "Picks top p % of the highest scoring proposals and surrounding ones as positives"
  • ConcreteDropBlock: "a data-driven and parametric drop-out to drop the most relevant regions"
  • Adversarial optimization

w*, θ* = arg minw maxθ ΣI Limg(w, θ) + Lroi(w, θ)

슬라이드엔 기호 정의가 없어서 논문으로 채웠어. w = detector parameter, θ = Concrete DropBlock parameter, ΣI = 학습 사진 전체에 대한 합이야. detector는 loss를 줄이고, DropBlock은 loss를 키워. Limg는 image label loss, Lroi는 pseudo label로 받는 proposal 단위 loss야.

왜 돼?얼굴이 가려지면 얼굴만으론 loss가 안 내려가. 그래서 몸통까지 봐야 해. "the detector is forced to attend to the entire object rather than only its most salient parts" (p.38). p.39는 결과 그림이야(Successful cases, Failure cases).

차이OICR · PCL은 pseudo label을 다듬고, Ren은 network 중간의 feature(그림의 Base와 Neck 사이)를 가려. 보통 dropout은 균등 무작위지만 이건 학습된 확률 map에서 샘플링해서 제일 중요한 영역을 더 자주 지워 (논문 보충). 그림의 regress. head는 WSDDN에 없던 bounding box regression이야. target은 진짜 box가 아니라 pseudo box야(논문 보충).

  • WSOD is an ill-posed problem and ambiguous due to part/whole and co-occurence issues.
  • WSOD training is sensitive to initialization and prone to overfitting.
  • Remarkable progress due to objectness and region proposals, incorporating prior knowledge and additional cues, end-to-end learning.
  • Addressing the inherent ambiguity requires better objectness measures and stronger additional cues.

RL로 번역

슬라이드 밖 비유라서 시험 범위가 아니야. 각 줄의 단서까지 같이 봐.

  • bag label ↔ episode-level sparse reward. 어느 window(timestep)가 잘한 건지 모르는 credit assignment야. 단 MIL은 "적어도 하나"고 return은 합이야.
  • Re-train / Re-localize ↔ generalized policy iteration. 고정한 box로 fit하고, greedy argmax로 고르기를 개선해. hard EM으로 봐도 돼. 단 tabular policy iteration은 optimal policy로 수렴하지만, 여기선 local minimum에 갇힐 수 있어 (p.16).
  • locking ↔ exploration 없는 greedy policy + bootstrapping error 누적.
  • hard max → log-sum-exp ↔ hard Bellman max → soft value V = α log Σ exp(Q/α) (soft Q-learning, SAC(Soft Actor-Critic)). 같은 연산이고 여기선 α = 1이야.
  • Multifold MIL ↔ cross-fitting. 고르는 detector가 그 샘플로 fit되지 않았어. Double Q와는 "고르기를 자기 추정에서 떼어 낸다"는 동기만 닮았어. Double Q는 고르는 쪽과 값을 매기는 쪽을 나누는 거라서, 샘플을 빼고 고르는 multifold와 메커니즘이 달라.
  • Self-paced · Scale prior ↔ curriculum RL.
  • λA + (1−λ)Obj ↔ 점수에 task-agnostic prior 섞기. 단 potential-based shaping은 아니야.
  • OICR 단계 사슬 ↔ 각 head의 target이 앞 head에서 오는 bootstrapped target chain. 단 EMA는 없어.
  • Ren의 min-max ↔ robust adversarial RL. adversary가 방해하고 agent가 버텨. Concrete DropBlock이 마스크를 뽑을 때 쓰는 Gumbel-Softmax(논문 보충, 뽑기를 미분 가능하게 만드는 방법) ↔ relaxed discrete action.
시험 함정
  • Weak supervision: 약한 쪽은 train annotation이고, 기준은 test 때 필요한 출력이야 (p.4).
  • bags = images, instances = windows. 아는 건 bag label이고 instance label은 몰라 (p.15).
  • Semi = labeled + unlabeled. Weakly semi = labeled + weakly labeled (p.5).
  • Re-train은 detector를 바꾸고 Re-localize는 box를 바꿔 (p.16). Challenges = initialization + overfitting(locking).
  • Re-train에서 positive 사진은 positive 1개, positive 사진의 negative는 없음 (p.21).
  • Relaxing max는 window 여러 개를 살려서 initialization에 덜 민감해져 (p.22).
  • Multifold: positive는 all folds but k, negative는 전부. box를 고르는 detector는 그 사진을 본 적 없어야 해 (p.24).
  • Additive = context와 compatible, Contrastive = context에서 outstanding (p.27).
  • Objectness는 class-independent, "object of any class" (p.28).
  • Scale 순서는 bigger → smaller (p.30). 반대로 쓴 지문 조심.

Gray box vs White boxp.19–20

핵심Gray box는 "Utilize the internal information in the network"야. "it identifies which areas the model focused on for classification by leveraging the activations or gradients within the CNN" (p.20). White box는 p.20엔 이름만 있고, 내용은 p.24–25의 CAM이야.

Gradient saliency · SmoothGradSimonyan 2014 · Smilkov 2017 · p.21–23Deep Inside Convolutional Networks: Visualising Image Classification Models and Saliency Maps (ICLR 2014 workshop)SmoothGrad: removing noise by adding noise (arXiv 2017)

한 줄class 점수를 입력 사진으로 미분해서 영향이 큰 pixel을 찾고(Simonyan), noise를 섞어 여러 번 재고 평균해서 잡음을 지워(SmoothGrad).

어떻게Simonyan (p.21): "Step 1) Train an ImageNet classifier." "Step 2) Calculate how much the score changes when the input is slightly modified." 식으로는 ∂Sc/∂I |I0야. Sc = class c의 점수, I = 입력 사진, |I0 = 지금 보는 사진에서 계산한다는 뜻이야. 이 지도가 saliency map이야.

문제"The problem is that it is extremely noisy." "the gradient measures sensitivity at the level of individual pixels, resulting in a "salt-and-pepper" appearance." (p.21). pixel 하나 단위의 미분이라 이웃 pixel끼리 값이 들쭉날쭉해.

어떻게SmoothGrad (p.22):

  1. Train a standard CNN classifier.
  2. Add small random noise to the images.
  3. Calculate the gradient for each.
  4. Average. 그림 글자: "Repeat 50 times step 2&3, average result".

식으로 쓰면 M̂c(I) = (1/n) Σi Mc(I + εi), εi ~ N(0, σ2)이야. Mc = Simonyan의 gradient map, n = 반복 횟수(그림에선 50)야. 식은 노트 보충이고 슬라이드엔 단계만 있어.

왜 돼?pixel 단위의 들쭉날쭉한 값은 noise마다 방향이 달라서 평균하면 서로 상쇄돼. 물체 쪽에서 일관되게 큰 값만 남아. "The key point is that calculating the gradient multiple times and averaging it removes noise and yields a more meaningful saliency map." (p.22)

문제noise를 지워도 남는 한계가 있어. "Key issue: Asking apples from the oranges tree. Classifier was not built nor trained to segment objects." classifier는 "highlights only the specific regions necessary for classification rather than the entire object" (p.23). 분류용으로 만든 모델한테 segmentation을 시키는 격이야.

차이Simonyan은 gradient를 한 번 재고, SmoothGrad는 noise를 넣어 50번 재서 평균해. noise는 입력 사진에 넣어. gradient에 넣는 게 아니야. 둘 다 구조를 안 바꾸는 gray box야.

CAMZhou 2016 · p.24–26Class Activation MappingLearning Deep Features for Discriminative Localization (CVPR 2016)

한 줄classifier 끝을 GAP + 선형 layer로 바꿔서, class 점수를 위치별 기여 지도로 바로 펼쳐 봐.

문제gray box는 위치를 버리는 FC layer를 그대로 둔 채 gradient를 따로 계산해야 했고, 결과도 noisy했어.

어떻게구조를 세 단계로 바꿔 (p.24).

  1. "eliminate the FC layer": FC는 feature map을 한 줄로 펴서 다 섞는 layer라 "어느 위치에서 온 값인지"가 사라져.
  2. "add GAP (Global Average Pooling)": GAP은 channel마다 feature map 한 장의 평균값 하나를 내.
  3. "add a 1×1 convolution that performs a linear combination of the features": 위치끼리는 안 섞고 channel끼리만 섞어. class마다 weight 한 벌이 있어.

← slide는 "FC를 없애고 1×1 conv"라고 적었는데, 원 논문(Zhou 2016)에선 마지막 conv → GAP → 선형(FC) layer + softmax야. GAP 뒤엔 위치가 1×1뿐이라 둘은 같은 연산이야: channel별 평균값의 선형 결합(weight wkc). 시험엔 slide 표현을 쓰고, "FC를 없앤다"는 건 feature map을 한 줄로 펴서 위치를 섞는 FC를 뺀다는 뜻으로 읽어.

핵심분류에 쓴 weight를 feature map에 그대로 곱해 더하면 그 class의 CAM이야. "since the network itself is designed to preserve spatial information, activation maps can be obtained directly without the need for separate gradient calculations." (p.25)

Mc(x, y) = Σk wkc fk(x, y)

fk(x, y) = 마지막 conv의 k번째 feature map에서 위치 (x, y)의 값, wkc = feature k가 class c에 얼마나 중요한지(그림의 w1, …, wn), Mc = class c의 CAM이야. 슬라이드엔 그림 속 "w1 * map + w2 * map + … = Class Activation Map"만 있고, 식은 노트 보충이야.

왜 돼?GAP(평균)과 선형 결합(w)이 둘 다 선형이라 순서를 바꿔도 돼. Sc = Σk wkc (1/Z) Σx,y fk(x, y) = (1/Z) Σx,y Mc(x, y). 즉 class 점수가 CAM의 평균이야(Z = 위치 개수, bias는 원 논문처럼 0으로 둠). 그래서 map을 얻을 땐 forward 때 계산한 feature map과 weight만 있으면 돼. classifier를 학습할 땐 당연히 backprop을 써.

설명용 숫자야. 2×2 feature map 두 장: f1 = [[4, 0], [0, 0]](머리에 반응), f2 = [[0, 0], [2, 2]](몸에 반응). dog weight w = (1, 0.5)면 Mdog = [[4, 0], [1, 1]]이고 평균 1.5가 Sdog와 같아. 머리 칸 4가 압도적이라 threshold하면 머리만 남아. discriminative area only 문제가 여기서 보여.

"Designed to Generate Per-Class Maps" (p.26). 같은 feature map에 class별 weight만 바꿔 곱하니까 class마다 지도가 하나씩 나와. 정답이 dome인 사진의 top 5 예측(palace 0.459, dome 0.195, church 0.146, altar 0.091, monastery 0.051)마다 지도가 따로 나와. 특히 palace(건물 아래 넓은 부분)와 dome(위쪽 지붕)은 확 달라. 나머지 셋(church · altar · monastery)은 서로 비슷해.

CAM 보강: not sharp · discriminative only (p.28–42)

여기부턴 슬라이드가 두 문제 줄을 반복하면서 "⇢ 처방"을 하나씩 붙여. 슬라이드 헤더 기준으로 1번(not sharp) 처방은 resolution · SEC · saliency · SEAM이고, 2번(discriminative only) 처방은 Hide-and-Seek · Adversarial Erasing이야. 단 본문을 보면 SEC와 saliency는 2번도 건드려.

Good, but not good enoughp.28–29

한 줄CAM은 경계가 뭉개지고, 분류에 결정적인 부분만 켜.

  1. "Resulting masks are not sharp"
  2. "Focused on discriminative area only"

왜 어려워?두 문제는 원인이 달라. not sharp는 해상도와 경계 정보가 모자라서야. discriminative area only는 분류 loss가 그걸로 충분해서야. 타조는 긴 목만 봐도 맞히니까 나머지에 반응할 이유가 없어(discriminative part, L08과 같은 뿌리).

SECKolesnikov & Lampert 2016 · p.30–32Seed, Expand, ConstrainSeed, Expand and Constrain: Three Principles for Weakly-Supervised Image Segmentation (ECCV 2016)

한 줄CAM의 확실한 곳만 seed로 쓰고(Seed), image label로 넓히고(Expand), CRF로 경계에 맞추는(Constrain) 세 loss로 segmentation network를 학습해.

문제CAM limitations (p.31): "Activation maps are small and coarse", "Focus only on discriminative regions", "Poor object boundaries".

핵심"Three complementary losses" (p.31). 문제마다 loss를 하나씩 둬.

  • Seeding Loss: "Use CAM as reliable foreground seeds", "Preserve highly confident object regions". seed가 찍힌 pixel에서만 cross-entropy를 걸어.
  • Expansion Loss: "Encourage predictions to expand beyond the seeds", "Use image-level labels via Global Weighted Rank Pooling (GWRP)".
  • Constrain-to-boundary Loss: "Refine predictions using CRF", "Encourage masks to align with image boundaries".

어떻게GWRP는 pixel 점수를 큰 순서로 세우고, 순위가 내려갈수록 작은 weight dj−1로 평균하는 pooling이야(식은 논문 보충). d = 0이면 max pooling, d = 1이면 average pooling이야. max는 1등 pixel 하나만 봐서 넓힐 이유가 없고, average는 작은 물체도 사진 전체를 덮게 밀어. GWRP는 그 중간이라 꽤 많은 pixel이 높아야 점수가 높아. (논문 보충) d는 경우마다 달라: 사진에 없는 class는 d− = 0(max pooling, 어느 pixel도 높지 않게 눌러), 있는 class는 d+ = 0.996, background는 dbg = 0.999야. 슬라이드엔 GWRP 이름만 있어.

예시로 보면

설명용 숫자야. pixel 5개, d = 0.5면 weight는 [1, 0.5, 0.25, 0.125, 0.0625]이고 합 Z = 1.9375야. 2 pixel만 켜진 [0.9, 0.9, 0, 0, 0]은 max 0.9, GWRP ≈ 0.70이야. 4 pixel로 넓어진 [0.9, 0.9, 0.9, 0.9, 0]은 max 0.9 그대로, GWRP ≈ 0.87이야. GWRP만 넓어질수록 올라서 expansion loss가 넓히는 쪽으로 밀어.

슬라이드 요약 (p.31): "Seed: Preserve reliable CAM activations." "Expand: Grow seeds to cover the entire object using image-level supervision." "Constrain: Refine object boundaries with CRF-based regularization."

왜 돼?seed는 좁지만 거의 맞아서 세게 학습해도 안전해. seed 밖은 정답을 모르니까 "image 점수가 높으려면 꽤 넓어야 해"라는 약한 압력만 줘. 넓히다 경계를 넘는 건 CRF가 색 경계에서 멈추게 해. 논문에선 foreground seed만 CAM에서 오고, background seed는 별도 gradient saliency에서 와(논문 보충).

차이슬라이드는 SEC를 1번 처방 "Use boundary-aware propagation"(p.30)으로 소개하지만, expansion loss는 2번(discriminative only)도 겨냥해. 그래서 p.31이 세 limitation을 다 적어. CRF는 L08 p.25의 CRF와 이름만 같아. L08은 node = image(사진끼리 닮은 window 고르기), 여기는 node = pixel(색과 위치가 가까운 pixel끼리 label 맞추기)이야.

Saliency-guided (Oh)Oh 2017 · p.33–34Exploiting Saliency for Object Segmentation from Image Level Labels (CVPR 2017)

한 줄미리 학습한 saliency 모델에서 "물체가 어디까지인가"를, CAM에서 "그게 무슨 class인가"를 빌려 와서 합친 pseudo mask로 학습해.

문제CAM은 discriminative part만 켜고 경계도 흐려. image label엔 범위 정보가 전혀 없어.

핵심두 단서의 장단점이 정확히 반대야 (p.34 Observation).

  • CAM: "Provides class-specific localization", "Covers only discriminative regions"
  • Saliency: "Provides complete object extent", "Class-agnostic foreground estimation"

그래서 "Combine CAM and saliency to generate class-specific pseudo masks" (p.34).

  1. Seeder: "Generate class-specific seeds from CAM."
  2. Saliency: "Estimate foreground regions."
  3. Guide Labeller: "Fuse both cues into pseudo masks."
  4. Segmentation CNN: "Learn dense pixel-wise predictions."

왜 돼?saliency는 사람과 자전거를 통째로 칠하지만 어느 쪽이 person인지 몰라. CAM seed가 사람 위에 person, 자전거 위에 bicycle 이름표를 붙여. 둘을 합친 pseudo mask는 class도 맞고 범위도 넓어.

차이p.33의 처방 문구는 "Use transfer learning", "We could also use saliency cues"야. saliency 모델은 이 task가 아닌 다른 data로 학습돼서 transfer야. SEC는 seed를 loss로 넓히고, 이 방법은 넓힌 pseudo mask를 학습 전에 만들어 놓고 평범하게 학습해. 헤더는 1번(not sharp)이지만 "complete object extent"라서 2번도 메워.

SEAMWang 2020 · p.35–36Self-supervised Equivariant Attention MechanismSelf-supervised Equivariant Attention Mechanism for Weakly Supervised Semantic Segmentation (CVPR 2020)

한 줄원본 사진과 변환한 사진의 CAM이 "변환만큼만" 다르게 나오도록 classifier를 학습시켜. "Activation maps should be equivariant to the input" (p.35).

문제"CAMs are often coarse and inconsistent", "Small input transformations can produce different activation maps" (p.36). 같은 비행기를 크기만 바꿔 넣었는데 CAM 모양이 달라져.

핵심equivariance = 입력을 변환하면 출력도 같은 방식으로 변환된다는 성질이야. F(A(I)) = A(F(I)). invariance(F(A(I)) = F(I), 출력이 안 변함)와 구분해. 분류 답은 invariant해야 하지만 CAM과 mask는 equivariant해야 해. "Apply geometric transformations (e.g., affine transform)", "Predict CAMs for both original and transformed images", "Enforce consistency after compensating for the transformation" (p.36).

  1. 사진 I와 변환한 A(I)를 weight를 공유하는 CNN 두 갈래(Siamese network)에 넣어.
  2. 각 갈래에서 CAM ŷo, ŷt를 만들어.
  3. PCM이 CAM을 다듬어 yo, yt를 내. PCM은 "a module that propagates CAM activations to other pixels within the same object by utilizing pixel-wise affinity among CNN features"야 (p.36).
  4. 세 loss로 학습해: Classification Loss "Preserve image-level classification performance", Equivariant Regularization (ER) Loss "Encourage transformation-consistent CAMs", Cross-view Consistency (ECR) Loss "Align CAMs across different views". ← slide의 ECR 풀네임은 약자와 안 맞아. 논문 표기는 Equivariant Cross Regularization이야.

논문 식(슬라이드엔 없음): LER = ‖A(ŷo) − ŷt‖1, LECR = ‖A(yo) − ŷt‖1 + ‖A(ŷo) − yt‖1. 원본 쪽 map에 A를 걸어 준 다음 비교하는 게 "compensating"이야.

왜 돼?변환 A는 우리가 직접 걸었으니까 "A(I)의 CAM = I의 CAM에 A를 건 것"이라는 정답 관계를 사람 label 없이 알아. 그 관계가 supervision이라서 self-supervised야.

차이L08 p.29의 Equivariance prior를 CAM에 건 거야. SEC는 CAM에서 시작한 seed를 세 loss(seeding · GWRP를 쓰는 expansion · CRF constrain)로 segmentation network에 학습시키고, SEAM은 CAM을 내는 classifier 자체에 equivariance consistency loss를 걸어.

Hide-and-SeekSingh & Lee 2017 · p.37–38HaS = Hide-and-SeekHide-and-Seek: Forcing a Network to be Meticulous for Weakly-supervised Object and Action Localization (ICCV 2017) ← slide엔 "Wang et al. CVPR 2020"

한 줄학습할 때마다 사진의 칸 몇 개를 무작위로 가려서, classifier가 가장 쉬운 부분 하나에만 기대지 못하게 해.

문제"CAM activates only the most discriminative regions." (p.37) 개 얼굴만 봐도 "dog"를 맞히니까 CAM도 얼굴만 켜져.

어떻게Solution (p.37):

  1. 학습 사진을 격자 칸으로 나눠.
  2. "Randomly hide image patches during training." epoch마다 가려지는 칸이 달라.
  3. "Encourage learning from the remaining visible parts." 가려진 사진으로 평범하게 분류를 학습해. 슬라이드의 세 번째 Solution 줄은 "Generate more complete localization maps."야.

왜 돼?Effect (p.37): "The classifier is forced to discover other visible object parts." "CAM gradually covers a larger portion of the object." 얼굴 칸이 가려진 epoch엔 얼굴 없이 맞혀야 하니까 다리와 몸통도 쓰게 돼. "Random hiding encourages the network to discover complementary object parts instead of relying on a single discriminative region."

"Let us play peek-a-boo!" (p.38). 보통 학습한 AlexNet-GAP heatmap은 얼굴 한 점에 몰리고, HaS heatmap은 몸통까지 퍼져.

차이바뀌는 건 학습 data뿐이야. 구조와 loss는 그대로라 어떤 classifier에도 붙일 수 있어. 어디를 가릴지 모델을 보고 정하지 않아(random). 이게 9-3-6 Adversarial Erasing과 갈리는 지점이야. ← p.37–38 cite는 바로 앞 SEAM의 cite가 남은 걸로 보여. 실제 논문은 Singh & Lee, ICCV 2017이고, p.11–17 하단 cite 목록 맨 끝에도 잘린 채 "Singh ICCV 17"로 보이는 항목이 있어. 시험 지문은 슬라이드 표기를 따를 수 있어.

Adversarial ErasingWei 2017 · p.39–41Object Region Mining with Adversarial Erasing: A Simple Classification to Semantic Segmentation Approach (CVPR 2017) ← slide엔 학회 없이 "Wei et al. 2017"

한 줄classifier가 가장 의존하는 곳(CAM이 제일 센 곳)을 지우고 다시 학습하는 걸 반복해서, 지운 영역들을 모아 물체 전체를 찾아.

문제Hide-and-Seek와 같아. CAM이 discriminative part만 켜.

핵심"Let us play adversarial peek-a-boo!", "(adversarial instead of random erasures)" (p.39). 무작위로 가리지 말고, 지금 classifier가 제일 믿는 곳을 골라 지워(erasing).

  1. 사진 It로 classification network를 image label로 학습해.
  2. heatmap(CAM) Ht를 구해.
  3. Ht를 threshold로 잘라 제일 센 영역 Ft를 얻어.
  4. 그 영역을 지워: It+1 = It ⊖ Ft
  5. It+1로 1번부터 다시 해. 그림은 t = 1, 2, 3이야 (Recurrent).
  6. 지운 영역 F1, F2, F3를 합친 mined object region을 segmentation network의 foreground pseudo label로 써. background는 saliency에서 따로 얻어(논문 보충).

AE-Step1 → 2 → 3으로 갈수록 heatmap의 빨간 곳이 다른 부분으로 옮겨 가 (p.40). 맨 아래 Erased Regions(회색)는 물체의 꽤 넓은 부분을 덮지만 전부는 아니야.

왜 돼?지우는 쪽이 classifier가 제일 믿는 단서를 골라 빼앗아. classifier한텐 방해꾼(adversary)이야. 그래서 남은 부분에서 다음으로 discriminative한 부분을 찾아야 해.

결과p.41 표(VOC 2012 test, mIoU, 비중 낮음): image label만 쓴 방법 중 AE-PSL 55.7이 맨 위야 (SEC 51.7, AF-SS 52.7. * 표시 AF-MCG 55.5는 pixel-level supervision을 암묵적으로 써서 따로 묶여). box supervision(WSSL 62.2, BoxSup 64.2)보다는 아직 낮아. 이 간격이 p.42 마지막 질문으로 이어져.

차이Hide-and-Seek는 random hiding을 한 번의 학습에 섞고, AE는 CAM 최고 영역을 지우고 재학습하는 걸 여러 step 반복해. L08 Ren의 Concrete DropBlock도 "most relevant" region을 지웠지만, 지울 곳을 network가 min-max로 같이 학습했어.

Webly Supervised Learning (p.43–52)

p.42의 질문 "How far can we go from image-level to pixel-level labels?"에 대한 답 하나가 정보원을 늘리는 것이야. 여기선 사람 annotation 대신 web 검색 사진을 끌어와.

Webly supervised learningShen 18 · Jin 17 · Chen 15 · p.44

한 줄web 검색으로 모은 사진을 supervision으로 써. 검색어가 곧 label이야.

"A learning method that uses data collected from the web as supervision." (p.44) webly supervised = web + weakly supervised야.

  • "Collect training images directly from web search engines."
  • "Enables large-scale learning without manual annotation."
  • "Labels are noisy, ambiguous, and incomplete."
  • "Learning must be robust to noisy supervision."

문제noisy = 검색어와 안 맞는 사진이 섞여. ambiguous = 한 단어가 여러 뜻이야(p.44 그림: "jasmine" 검색 결과에 공주 그림 · 분장한 사람과 jasmine 꽃이 같이 나와. 그림을 이렇게 읽은 건 해석이야). incomplete = 검색어 하나만 붙고, 같이 찍힌 다른 물체는 label에 없어.

핵심"Webly supervised learning leverages freely available web images as supervision, trading annotation cost for label noise." (p.44) 아끼는 건 annotation cost고, 받아들이는 건 label noise야.

차이사람 label 대신 공짜 data를 쓰고, 그 대가가 noise야. p.10 prior "Similarity with external images"의 external images를 web 검색으로 가져오는 방향으로 읽혀 (해석).

Model-T + Web-SEC (Shen)Shen 2018 · p.45–52Bootstrapping the Performance of Webly Supervised Semantic Segmentation (CVPR 2018)

한 줄target dataset의 clean image label로 학습한 classifier(Model-T)가 web 사진을 거르고, 거른 web 사진으로 pixel labeler(Web-SEC)를 학습해서, 두 쪽 mask를 합쳐 최종 model을 학습해.

문제image label만으로 만든 CAM mask는 거칠고 물체 일부만 잡아. 그런데 사람이 pixel label을 더 달긴 싫어.

어떻게Pipeline (p.45–50, 원문 순서):

  1. Train an image classifier (Model-T) on clean image-level labels.
  2. Use Model-T to filter noisy web images.
  3. Train Web-SEC (pixel labeler) using the filtered web images.
  4. Apply Web-SEC to generate pixel labels for the target images.
  5. Use Model-T to produce class activation maps (CAMs) on the target images.
  6. Fuse the two label sources and train the final segmentation model.

핵심p.47 원문 세 줄이 core idea야. "Unlike CAM-based methods, Web-SEC actually learns a pixel classifier." "The key observation is that web images are much cleaner—typically containing a single centered object—so approximate segmentation masks can be generated automatically." "...which learns generic object shapes and can later be transferred to the target dataset."

왜 돼?web 사진은 물체 하나가 가운데 있어서 "어디가 물체인가"를 사람 없이도 대략 정할 수 있어. 쉬운 data에서 물체 모양 일반을 배우고, 어려운 target으로 옮겨.

  • Model-T: target의 clean image label로 학습해. web 사진을 판정(filter)하고 target 사진의 CAM을 만들어 (1 · 2 · 5단계). web 사진으로 학습하진 않아.
  • Web-SEC: filter된 web 사진으로 학습하고 target 사진에 적용만 해 (3 · 4단계). 그림의 Model-W가 이 자리로 보여 ← 슬라이드는 둘을 직접 연결하지 않아 (추정).
  • Final model: 두 label을 합친 enhanced mask로 학습해 (6단계).

결과p.51–52 표(비중 낮음): Ours-Res50이 63.0(val)으로 fully supervised 줄 63.7에 가깝고, image label만 쓴 SEC 50.7보다 훨씬 높아. 추가 annotation 없이 Web만 더했어.

차이CAM 계열은 분류용 classifier에서 위치를 빌려 오고, Web-SEC는 처음부터 pixel을 분류하도록 학습해. 9-6-2 Liu에선 web이 dataset을 보충하는 게 아니라 대체해.

Boxly Supervised Learning (p.53–61)

이번엔 image label보다 정보가 많은 weak label인 bounding box를 써. "Box-level labels at training time" → "Pixel-level per instance labels at test time" (p.54).

Simple Does It (Khoreva)Khoreva 2017 · p.54–60Simple Does It: Weakly Supervised Instance and Semantic Segmentation (CVPR 2017)

한 줄box를 칠한 거친 mask로 segmentation network를 학습하고, 그 예측을 다음 round의 label로 쓰면서 mask를 점점 다듬어.

문제box 안을 통째로 칠하면(그래프의 Rectangles) 물체 밖 pixel이 많이 섞인 noisy label이야. 원하는 건 모양대로 칠한 mask(What we want)인데 가진 건 직사각형(What we have)이야 (p.55).

핵심"Convnets are robust to noise. Let us use that !" (p.56). "Initially, training is performed using a noisy mask, but the CNN's predictions are then used as pseudo-labels for retraining."

  • "Segmentation networks are robust to noisy supervision."
  • "Approximate masks are sufficient for training."
  • "Iteratively refine pseudo masks during training."
  • "Better masks lead to better segmentation."

어떻게recursive training이야.

  1. box를 칠한 직사각형 mask로 segmentation network를 학습해.
  2. 학습한 network로 training 사진의 mask를 다시 예측해.
  3. 그 예측을 pseudo-label로 써서 다시 학습해.
  4. 2–3을 반복해. 한 번이 training round 하나야.

왜 돼?슬라이드엔 이유 설명이 없어서 직관이야. box 안 배경 오류는 사진마다 위치와 모양이 제각각이고, 물체 모양은 사진끼리 공통이야. 그래서 network는 공통 패턴을 먼저 배우고, 사진마다 다른 오류까지 다 따라 하진 않아.

넓히기: Beyond CAM (p.62–95)

p.2 목차(1–4) 밖의 최신 세미나 논문 세 편이야. 슬라이드에 있으니까 시험 범위로 봐. 출발점은 여전히 CAM이고, p.62가 두 약점을 다시 적어: "CAM activates only the most discriminative regions", "CAM boundaries are coarse and inaccurate". 세 편 모두 CAM 하나로 못 메우는 정보를 바깥의 큰 model이나 data(CLIP · DINO, web · caption, SAM)에서 빌려 와.

CD-CLIPYang 2026 · p.62–74CDA = Class Distribution Aware · SBE = Super-class Boundary Exploration (p.66 그림)Leveraging Class Distributions in CLIP for Weakly Supervised Semantic Segmentation (CVPR 2026)

한 줄CLIP이 patch마다 내는 class 점수 분포 전체로 "어떤 patch끼리 같은 물체인가"를 다시 매겨서 CAM을 채우고(CDA), DINO feature로 어디서 멈출지 경계를 가르쳐(SBE).

문제문제가 두 개고 방향이 반대야 (p.64).

  1. Incomplete activation: "CAM focuses on the most discriminative part." "Other object regions remain inactive."
  2. Inaccurate boundaries: "Affinity propagation may spread activation." "Foreground activation can cross class boundaries." 덜 켜진 걸 퍼뜨려 고치면 이번엔 배경까지 번져(boundary leakage).

질문은 하나로 모여: "How can we expand CAMs without losing object boundaries?" (p.64)

먼저 용어. patch = ViT가 사진을 자른 작은 정사각형 조각이야. CLIP은 사진과 글을 같은 embedding 공간에 둔 model이라(L05), patch feature와 class 이름 text feature의 cosine similarity로 patch마다 모든 class의 점수를 바로 낼 수 있어. DINO feature는 label 없이 self-distillation으로 학습한 ViT의 feature야(L04). 물체 구조를 잘 따라가지만 class 이름은 몰라.

핵심"Target Score Is Not Enough" (p.65). 기존 affinity는 "feature or attention similarity between patches"를 쓰는데, "Similar appearance does not always imply the same class." 그래서 CD-CLIP은 이렇게 봐: "Every patch has scores over multiple classes." "Patches of the same semantic class show similar class distributions." 한 문장으로: "A patch is characterized not only by its target-class score, but by its distribution over all classes."

어떻게CDA (p.67–69):

  1. patch마다 class 분포를 만들어: Sa = Min-max(CosSim(F, Tall)). F = CLIP patch feature, Tall = target class와 super-class(여러 class를 묶은 상위 class)의 text feature 전부야.
  2. 두 patch 분포를 비교해: "Small JS divergence: similar class distributions", "Large JS divergence: different class distributions". Sd = (1 − DJS(Softmax(Sa) ‖ Softmax(Sa)T)) / τ, τ = temperature.
  3. affinity를 고쳐: Ad = Softmax(Sd) · Ainit. "Distribution similarity filters unreliable relationships in the original affinity." Ainit은 MHSA attention으로 만든 원래 affinity야.
  4. CAM을 퍼뜨려: Mrec = Minitc · (Ad)t. "CDA propagates activation from the head to the body."

기호 정리: Sd는 (patch i, patch j) 쌍마다 분포를 비교한 patch × patch 행렬이야. Minitc = class c의 초기 CAM, t = 전파 횟수(슬라이드에 정의 없음)야. 아래 SBE의 Fd = DINO patch feature, Msn = super-class n의 CLIP CAM, CAP = Class Average Pooling(p.66 범례)이야. loss의 P = decoder 예측, Ys = super-class pseudo label(슬라이드에 정의 없음), |Cp| = 사진에 있는 super-class 수야. JS 식의 P, M은 분포 기호라 이것들과 다른 글자야.

JS divergence는 DJS(P‖Q) = ½ KL(P‖M) + ½ KL(Q‖M), M = ½(P + Q)야. KL과 달리 대칭이고 유한해. 같은 분포면 0이고 다를수록 커서, 1 − DJS가 유사도가 돼.

예시로 보면

설명용 숫자야. class 4개 [person, bicycle, motorbike, sky]. 머리 patch [0.40, 0.30, 0.20, 0.10], 몸통 patch [0.25, 0.35, 0.25, 0.15], 하늘 patch [0.05, 0.05, 0.05, 0.85]. person 점수만 보면 머리 0.40과 몸통 0.25가 꽤 달라. 그런데 JS(log 밑 2)는 머리–몸통 ≈ 0.02, 머리–하늘 ≈ 0.46이야. 머리–몸통 연결은 살고 머리–하늘 연결은 약해져.

SBE (p.70–71): "CDA expands activation—but where should it stop?" 넓혔으니 이번엔 멈출 곳이 필요해.

  1. super-class prototype(한 그룹을 대표하는 평균 feature 벡터)을 만들어: "Use the CLIP super-class CAM as a semantic seed and average the corresponding DINO features." fsn = CAP(Msn ⊙ Fd)
  2. prototype CAM을 만들어: "Compare the prototype with every DINO patch to recover a complete and structurally coherent super-class region." Mpn = ReLU(CosSim(fsn, Fd))

Loss (p.72): L = Lseg + λ1 Lb. boundary-enhanced loss Lb는 Dice(P, Ys)인데, 사진에 있는 super-class 수가 2개 이상일 때만 걸고 아니면 0이야. "Apply boundary loss only when there are two or more distinct superclasses." 경계 supervision은 서로 다른 super-class가 맞닿은 곳에서만 의미가 있어서야 (p.73).

왜 돼?"CLIP gives the prototype a semantic identity, and DINO expands it into a coherent region" (p.71). CLIP은 이름표, DINO는 모양을 맡아. 넓히는 힘(CDA)과 멈추는 힘(SBE)을 따로 둬서 둘 다 챙겨.

결과p.73 (비중 낮음): "CDA significantly improves the CAM mIoU from 70.1 to 80.3." "SBE provides a greater improvement to the final segmentation performance than the CAM itself." SBE는 activation을 넓히는 게 아니라 decoder의 경계 학습을 도와.

차이SEAM의 PCM과 기존 MHSA affinity는 feature(겉모습) 유사도로 퍼뜨려. CDA는 class 분포 유사도로 affinity를 먼저 걸러. SEC는 CRF로 경계를 맞췄고, SBE는 DINO prototype CAM과 Dice로 가르쳐. Takeaway (p.74): "Better WSSS requires both knowing which patches belong together and knowing where their relationship should stop."

Learning from the Web (Liu)Liu 2024 · p.75–85WILSS = Weakly-supervised Incremental Learning for Semantic SegmentationLearning from the Web: Language Drives Weakly-Supervised Incremental Learning for Semantic Segmentation (ECCV 2024)

한 줄옛 학습 사진을 버린 상태에서, 새 class는 web 검색으로 배우고 옛 class는 저장해 둔 caption으로 web에서 비슷한 사진을 다시 받아 복습해.

질문 (p.75): "Can a segmentation model learn new classes from the web without storing its original training images?"

먼저 용어. incremental learning = step마다 새 class를 추가로 배우는 설정이야. catastrophic forgetting = 새 class만 배우면 옛 class 성능이 무너지는 현상이야. rehearsal = 옛 class 사진을 섞어 보여 줘서 잊지 않게 하는 거야. 보통은 옛 사진을 저장해 둬야 해.

문제Three challenges (p.78):

  1. "Web images have a different distribution."
  2. "Search queries provide noisy single-class labels."
  3. "Learning new classes causes forgetting of old classes."

"The web must provide both new knowledge and memory of old knowledge." (p.78)

핵심"Web images replace curated incremental data, while captions replace reliable manual image labels." (p.79) 그리고 "Language is used for querying, labeling, filtering, and rehearsal." (p.80)

  1. Retrieve web images: "Query the web using new class names." "Retrieve rehearsal images using stored captions."
  2. Filter noisy web images: "Domain filtering removes out-of-distribution images." "Caption filtering removes semantically irrelevant images."
  3. Generate supervision: "Captions are converted into multi-label supervision." "The previous model produces pixel-level pseudo-labels."
  4. Update the segmentation model: "Learn new classes from web images." "Rehearse old classes without storing original images."

새 class 쪽 (p.81): "The class name retrieves images; the caption determines their labels." 검색어 "Dog"는 label {dog} 하나뿐이지만, caption "a dog and a cat laying on a couch"는 {cat, dog, sofa}를 줘. Domain filtering은 dataset 쪽일 확률이 더 큰 사진(pds / pweb > 1)만 남겨.

옛 class 쪽 (p.82–83): "Store Captions, Not Images". "Old image → Stored caption q' → Web search → Rehearsal image". 받아 온 사진엔 새 caption q''를 달아 q'와 명사를 비교하고, 비슷한 의미 계열이면 남겨. "Captions serve as retrieval keys, and the web serves as external memory."

왜 돼?사진은 web에 이미 있어. 들고 있을 건 그걸 다시 찾아올 열쇠(caption)뿐이야. caption은 class 이름보다 장면을 자세히 말해서 옛 사진과 더 닮은 사진이 와 ("Caption queries retrieve semantically richer images than class-name queries", p.84).

결과p.84–85 (수치 비중 낮음): "Domain filtering reduces the web-to-dataset gap." "Caption labeling corrects incomplete single-class supervision." "The two components are complementary." 둘을 같이 쓰면 10–10 결과가 2.9점 올라. rehearsal 쪽은 "Querying and filtering work best together"이고 15–5가 3.6점 올라. "Caption-based rehearsal is particularly valuable in multi-step learning." (10–1에서 크게 향상, p.85)

차이9-4-2 Shen에선 web이 curated dataset을 보충했어. 여기선 web이 dataset을 대체하고, 옛 class의 memory 역할까지 해. "The web is not only a source of new data. It can serve as an external semantic memory." (p.85)

WISHKweon & Yoon 2025 · p.86–95WISH: Weakly Supervised Instance Segmentation using Heterogeneous Labels (CVPR 2025) ← slide엔 cite 없음

한 줄tag · point · box가 섞인 dataset을 한 model로 학습하는 instance segmentation 방법이야. SAM의 prompt space를 weak label들의 공용어로 써.

질문 (p.86): "Under a fixed annotation budget, should every image receive the same type of weak label?"

먼저 용어. instance segmentation = 물체 하나하나를 따로 mask로 내는 task야. tag = 사진의 class 목록(위치 없음), point = 물체마다 점 하나, box = 물체마다 box야. SAM(Segment Anything Model)은 prompt(점이나 box)를 주면 그 물체의 mask를 내는 큰 pretrained segmentation model이야. prompt 하나에 mask 후보를 3개 내 (p.94). object query는 Mask2Former에서 물체 하나를 맡는 학습 벡터야.

문제Homogeneous supervision(p.87): "Every training image uses the same weak label type." "Tags are cheap but provide no localization." "Boxes are informative but expensive." "Points provide an intermediate level of supervision." 기존 WSIS(Weakly Supervised Instance Segmentation)는 "Chooses one weak label type for the entire dataset" (p.95).

핵심Heterogeneous supervision: "Different images may use different weak label types." "A single model learns from all label types." (p.87) 공용어는 "SAM's prompt space serves as a common representation for heterogeneous supervision." (p.88)

  1. weak label을 prompt latent로 바꿔: "Point prompt → point latent", "Box prompt → box latent", "Tag → converted point prompt".
  2. query가 latent를 예측해: Ẑ = Hprompt(Q). Q = Mask2Former object queries, Hprompt = prompt prediction head야.
  3. Multi-stage matching (p.89–90): Class matching은 "what" ("identifies the semantic category"), Prompt matching은 "where" ("identifies the approximate instance location", 예측 latent와 label latent의 KLD), Mask matching은 "which SAM mask fits it best" (SAM 후보 3개 중 예측에 가장 가까운 것). 총 cost는 Cost = α·Costcls + β·Costprompt + γ·Costmask(p.89)이고, Hungarian matching이 이 cost가 최소가 되게 예측과 weak label을 1:1로 짝지어. 여기 β는 아래 예산 식의 βt, βp, βb와 다른 뜻이야.
  4. tag → point (p.91): CAM의 local maxima를 뽑아 "Each selected CAM peak becomes a positive point prompt." SAM이 점마다 instance mask를 내고, 겹치는 mask는 묶어. "CAM supplies missing spatial cues, and SAM turns those cues into instance-level masks."
  5. self-enhancement (p.94): "Current instance masks refine the CAM." "Improved CAMs generate better point prompts for tag supervision."

왜 돼?p.93: "Tags Provide Coverage" (많은 사진, 다양한 모습), "Points and Boxes Provide Localization". "Cheap labels provide breadth, while strong labels provide spatial precision." 정보가 한 model 안에서 섞이는 건 "SAM's prompt space transfers information across label types" 덕분이야.

예산 식 (p.92): Ntβt + Npβp + Nbβb = ζ. N = 그 label(tag, point, box)을 단 사진 수, β = label 종류별 장당 비용(슬라이드엔 설명 없음), ζ = 고정된 총 annotation 예산이야.

결과p.92 (같은 예산, 비중 낮음): tag만 46.0, point만 44.7, box만 45.1인데, 섞으면 tag + point 47.3, tag + box 48.3이야. "A balanced mixture can outperform either weak label alone under the same annotation cost." p.94: SAM 후보 3개 중 현재 예측에 가장 가까운 걸 고르는 adaptive 선택이 고정 mask level보다 좋고("Adaptive selection outperforms using a fixed mask level"), prompt matching은 "Helps the model learn instance identity without mask ground truth". "Prompt matching, adaptive mask selection, and self-enhancement are complementary."

차이CAM 모양 전체를 쓰지 않고 봉우리 위치만 써. 모양은 SAM이 그려. CAM이 "어디쯤", SAM이 "어디까지"를 맡는 분업이야. 결론 (p.95): "The optimal supervision strategy may be a portfolio of weak labels, not a single annotation type."

RL로 번역

슬라이드 밖 비유라서 시험 범위가 아니야. 각 줄의 단서까지 같이 봐.

  • CAM의 Sc = 평균x,y Mc(x, y) ↔ multi-agent RL의 value decomposition(VDN, Qtot = Σi Qi). "어느 위치가 점수를 벌었나"는 credit assignment 질문이야. 단 정확히 쪼개지는 건 head가 선형이고 bias를 무시할 때뿐이야.
  • gradient saliency ∂Sc/∂I ↔ critic의 ∂Q/∂s 같은 local sensitivity. SmoothGrad의 평균 ↔ sample을 많이 모아 gradient 분산을 줄이는 것. 단 SmoothGrad의 noise는 입력에 일부러 넣고, REINFORCE의 noise는 policy sampling에서 와.
  • GWRP weight dj−1 ↔ discount γt의 모양. d = 0이 myopic, d = 1이 전부 같은 비중이야. 단 j는 시간이 아니라 점수 순위야.
  • SEC Constrain(CRF로 다듬은 출력을 KL target으로) ↔ 개선 연산자로 만든 target을 따라가게 하는 distillation(AlphaZero가 MCTS policy를 따라가는 구도). 단 CRF엔 학습 parameter가 없고, 원 논문은 gradient를 CRF까지 통과시켜 흘려 보내(target이 완전히 고정된 건 아니야).
  • SEAM equivariance ↔ 이미지 RL의 augmentation(DrQ · RAD)은 Q가 변환에 invariant하게 만들어. pixel 위 heatmap을 출력하는 policy(pick-and-place)는 SEAM처럼 equivariant해야 해.
  • Hide-and-Seek ↔ domain randomization(무작위 방해), Adversarial Erasing ↔ robust adversarial RL(adversary가 agent가 기대는 단서를 빼앗음). 둘 다 shortcut 하나에 기대는 걸 막아.
  • Boxly recursive training ↔ fitted Q iteration의 target 갱신. 오차가 쌓이는 위험(bootstrapping error)도 같아. box 제약 ↔ offline RL의 support constraint와 동기만 닮았어.
  • CD-CLIP의 분포 비교 ↔ 두 state를 greedy action 하나의 Q값이 아니라 policy 분포 π(·|s) 전체로 비교하기(KL · JS). (Ad)t ↔ transition matrix를 t번 곱하기. 단 Ad의 줄 합이 1이라는 말은 슬라이드에 없어.
  • Liu의 caption rehearsal ↔ replay buffer. 단 buffer에 transition이 아니라 다시 찾아올 검색어만 넣고, 다시 받은 사진은 원본과 같지 않아. forgetting ↔ continual RL의 policy drift.
  • WISH Hungarian matching ↔ agent와 task를 1:1로 배정하는 assignment problem. heterogeneous label ↔ 대량의 싼 play data + 소량의 expert demo를 섞는 data mix.
시험 함정
  • Priors는 "independent of any particular image sample", Hints는 "indirect supervision received for each image"야. 둘을 뒤바꾼 지문 조심 (p.5).
  • Gray box는 network 안의 "activations or gradients"를 써 (p.20). White box(CAM)는 구조를 바꿔서 map에 "separate gradient calculations"가 필요 없어 (p.25). 학습엔 backprop을 써.
  • gradient saliency가 noisy한 이유는 pixel 단위 sensitivity라서야(salt-and-pepper, p.21). SmoothGrad는 noise를 입력 사진에 넣고 gradient를 평균해 (p.22).
  • CAM 구조: FC를 빼고 GAP + 1×1 conv를 넣어 (p.24). FC를 더하는 게 아니야.
  • Seeds: high → foreground, low → background (p.27).
  • SEC: Seeding = CAM seed, Expansion = image label + GWRP, Constrain = CRF로 경계 (p.31). expansion과 constrain을 맞바꾼 지문 조심.
  • CAM = class-specific이지만 일부만, saliency = class-agnostic이지만 물체 전체 (p.34).

빈칸은 한 요소이고, 무게는 과정 설명에 있어. 설명 순서는 입력 → target은 어디서 오나 → loss → 누가 update되나야.

Standard MILWS-1 · p.20–21
scores = A(feats_pos).squeeze(1)        # A(x_b) for every proposal of a positive image
b_star = scores.argmax()                # re-localize
s_pos = A(feats_pos[b_star]).squeeze()  # only one positive instance per image
s_neg = A(feats_neg).squeeze(1).max()   # best window of a negative image

loss.backward()                         # re-train

한 줄1등 window 하나를 positive로 정하고, negative 사진의 1등 window를 −Δ 아래로 밀어.

입력 → 출력positive 사진의 proposal feature, negative 사진의 proposal feature, margin delta를 받아서 hinge loss를 돌려줘.

핵심 줄

  1. scores.argmax(): Re-localize야. 이 줄 때문에 사진당 positive가 하나뿐이야 ("Only one positive instance per image", p.20).
  2. .max(): negative 쪽 1등까지 −Δ 아래로 밀면 모든 window가 그 아래가 돼 (p.21).

core idea어느 window가 positive인지는 사람이 아니라 현재 detector의 argmax가 정해. 그래서 틀리면 locking이 돼.

알아보는 법argmax로 하나만 고르고 hinge(F.relu)를 써. 이 코드엔 softmax가 없어. 단 p.21엔 Softmax를 쓰는 cross-entropy 형태도 같이 있어.

End-to-end 가족: network 안에서 합치기

두 카드는 이어져. WSDDN의 proposal 점수 s가 OICR 첫 단계의 s_prev가 돼.

WSDDNWS-2 · p.34, 36
s_cls = fc_cls(x).softmax(dim=1)        # x: [R, D] region features -> [R, C]
s_det = fc_det(x).softmax(dim=0)        # localization stream
s = s_cls * s_det                       # proposal scores [R, C]

loss = F.binary_cross_entropy(y.clamp(0, 1), labels)

한 줄class 비교와 proposal 비교를 곱하고, proposal을 합쳐서 image label로 학습해.

입력 → 출력proposal feature x([R, D])와 image label labels([C], 0 또는 1)를 받아서 loss를 돌려줘. s가 곧 proposal별 detection 점수야.

핵심 줄

  1. softmax(dim=0): localization stream이야. "Compares regions for each class" (p.34).
  2. s.sum(dim=0): sum over proposals야 (p.36 그림). 여기서 instance 점수가 image 점수로 바뀌어.

core ideatarget은 image label뿐이야. box label 없이 proposal 점수가 implicit하게 생겨. 식과 loss는 논문 보충이고 슬라이드엔 구조만 있어.

알아보는 법softmax가 서로 다른 dim으로 두 번 나오고, 둘을 곱해.

OICRWS-3 · p.36–37
with torch.no_grad():                    # build the pseudo label
    top = s_prev[:, c].argmax()         # highest scoring proposal of class c
    near = iou(boxes, boxes[top:top + 1]).squeeze(1) > t  # plus surrounding ones
target = torch.full((R,), C)            # C = background, the (C+1)-th class

loss = F.cross_entropy(head_k(x), target)  # stage-k instance classifier

한 줄앞 단계 점수로 pseudo label을 만들고 다음 단계 head를 cross-entropy로 학습해.

입력 → 출력앞 단계 점수 s_prev(첫 단계는 [R, C], 그 뒤는 background까지 [R, C+1]), proposal 좌표 boxes, 사진에 있는 class c, IoU 기준 t를 받아서 단계 k의 loss를 돌려줘. 설명을 줄이려고 class 하나만 다뤘어.

핵심 줄

  1. s_prev[:, c].argmax(): "highest scoring proposal" (p.37). 어느 class인지는 image label이, 어느 proposal인지는 앞 단계 점수가 정해.
  2. torch.no_grad(): 이 코드가 넣은 표시야. label이 argmax와 IoU에서 나오니까 label 값으로는 gradient가 안 흘러. 논문이 detach라고 적은 건 아니야.

core ideaL07 pseudo labeling을 instance 단위로, 한 network 안에서 online으로 해. 나머지 proposal을 background(마지막 번호 C)로 두는 건 논문 보충이야. update되는 건 head_k와 공유 proposal feature고, 앞 단계가 멈추는 게 아니야. 모든 단계의 loss를 더해서 한 network로 같이 학습해 (논문 보충). 그래서 "Online"이고 Standard MIL의 alternating과 달라.

알아보는 법argmax + IoU로 target 벡터를 만들고, cross_entropy로 proposal을 직접 분류해. class 수가 background까지 C + 1개야.

sal = torch.stack(grads).mean(dim=0).abs().amax(dim=0)    # combine the n gradients, then |.| max over RGB

한 줄입력에 작은 noise를 넣고 구한 gradient를 여러 번 평균해서, 지저분한 saliency map을 깨끗하게 만들어.

입력 → 출력이미 학습된 분류기, 사진 img, class c를 받아서 pixel마다 중요도 sal([H, W])을 돌려줘. loss도 label도 없어.

핵심 줄

  1. img + sigma * torch.randn_like(img): "Add small random noise to the images" (p.22 Step 2).
  2. torch.stack(grads).mean(dim=0): "Average" (p.22 Step 4). gradient 하나는 pixel 단위라 "salt-and-pepper"처럼 지저분한데(p.21), 평균하면 우연한 잡음이 상쇄돼.

core ideagradient ∂Sc/∂I는 "이 pixel을 조금 바꾸면 class 점수가 얼마나 변하나"야. n = 1, sigma = 0이면 Simonyan의 vanilla gradient(p.21)와 같아. update되는 건 없어. gradient는 weight가 아니라 입력으로 가.

알아보는 법randn_like로 noise를 넣고, autograd.grad(score, x)로 입력 gradient를 구하고, mean으로 평균해.

CAMWS-9 · p.24–27
feat = backbone(img)                     # F: [K, h, w], last conv feature maps
logits = fc(feat.mean(dim=(1, 2)))       # GAP -> FC -> class scores [C]
loss = F.multilabel_soft_margin_loss(logits[None], labels[None])  # image labels only
loss.backward()                          # train backbone + fc as a classifier
cam = torch.einsum('k,khw->hw', fc.weight[c], feat)  # M_c = sum_k w_{k,c} F_k
cam = F.relu(cam) / F.relu(cam).max()    # [h, w], scaled to 0..1
cam = F.interpolate(cam[None, None], size=img.shape[-2:], mode='bilinear')[0, 0]  # resize
fg = cam > tau                           # B_c: confident foreground

한 줄GAP 분류기를 image label로 학습한 뒤, 그 FC weight로 마지막 feature map을 가중합하면 class별 위치 지도가 나와.

입력 → 출력사진 img와 image label labels([C], 0 또는 1)로 학습하고, class c의 CAM과 foreground mask fg(사진 크기)를 돌려줘.

핵심 줄

  1. fc(feat.mean(dim=(1, 2))): GAP 다음 FC야 (p.24 Step 2–3). GAP와 FC가 둘 다 선형이라 class 점수 = CAM의 평균 + bias야.
  2. torch.einsum('k,khw->hw', fc.weight[c], feat): Mc = Σk wk,cFk (p.25, p.27 M2). 분류에 쓰던 weight를 그대로 위치 지도에 써.

core idea"activation maps can be obtained directly without the need for separate gradient calculations" (p.25). target은 image label뿐이고, update되는 건 backbone과 fc야. 마지막 두 줄은 p.27 M3(resize → > τloc)이고, 이렇게 남긴 확실한 영역이 seed야.

알아보는 법mean(dim=(1, 2))(GAP)와 fc.weight[c]가 같이 나와. autograd.grad나 backward로 지도를 구하지 않아. p.27 그림은 k가 class, C가 channel 수라서 기호가 반대야.

L09 넓히기 가족: 물체 전체 · box에서 mask로

두 카드 모두 모델이 만든 결과를 다음 학습에 다시 넣는 반복이야. 반복 사이에 무엇을 바꾸나가 달라: AE는 입력 사진을 지우고, Boxly는 label을 갈아 끼워.

Adversarial ErasingWS-11 · p.39–41
mined = torch.zeros(H, W, dtype=torch.bool)    # union of erased regions
x = img.clone()                                # I_1
for t in range(T):                             # T = 3 steps in the p.39 figure
    net = train_classifier(x, labels)          # retrain on the erased image
    heat = cam(net, x, c)                      # H_t: [H, W], scaled to 0..1
    F_t = heat > tau                           # F_t: most discriminative region
    mined |= F_t                               # accumulate the mined object region
    x[:, F_t] = mean_pixel                     # erase it: I_{t+1}

한 줄CAM이 가장 센 곳을 지우고 다시 학습하는 걸 반복해서, 물체의 다른 부분까지 찾아.

입력 → 출력사진 img, image label labels, class c, threshold tau를 받아서 지운 영역의 합 mined([H, W])를 돌려줘.

핵심 줄

  1. heat > tau: CAM이 높은 곳, 즉 가장 discriminative한 부분 Ft를 골라.
  2. x[:, F_t] = mean_pixel: 그 부분을 지워서 It+1을 만들어 (p.39 그림). 다음 step 분류기는 남은 부분으로 맞혀야 해.

core ideastep마다 target은 image label 하나고, update되는 건 그 step의 분류기야. 지운 영역의 합집합이 물체 전체에 가까운 영역이 돼 ("The Mined Object Region"). 설명용 toy로 3 step 돌리면 누적 영역이 10 → 84 → 106 pixel(물체 120)로 늘어.

알아보는 법loop 안에서 다시 학습(train_classifier)하고, > tau로 고른 곳을 지우고, |=로 모아. Hide-and-Seek은 torch.rand로 무작위로 가려 ("adversarial instead of random erasures", p.39).

Simple Does It: recursive trainingWS-12 · p.55–59
label = box_lbl.clone()                  # round 0: filled boxes, [B, H, W], 0 = background
for r in range(R):
    net = train_segnet(imgs, label)      # learn from the noisy masks
    with torch.no_grad():
        pred = net(imgs).argmax(dim=1)   # [B, H, W] predicted classes
    pred[box_lbl == 0] = 0               # outside every box -> background
    label = pred                         # next round's training label

한 줄box를 통째로 칠한 거친 mask로 학습하고, network 예측을 다음 round의 label로 바꿔 끼우는 걸 반복해.

입력 → 출력사진 imgs와 box를 class 번호로 칠한 box_lbl([B, H, W], 0 = background)을 받아서 다듬어진 pixel label label을 돌려줘.

핵심 줄

  1. pred[box_lbl == 0] = 0: box 밖은 늘 background로 되돌려. box가 주는 확실한 정보야 (논문 보충).
  2. label = pred: "the CNN's predictions are then used as pseudo-labels for retraining" (p.56).

core idea"Segmentation networks are robust to noisy supervision" (p.56). 첫 target은 채운 box, 그다음부턴 network 자기 예측이고, update되는 건 segmentation network야. 설명용 toy로 3 round 돌리면 box 안 pixel 정확도가 0.44 → 0.96이 돼.

알아보는 법round loop 안에서 argmax로 예측을 만들고, box 밖을 0으로 자르고, label을 덮어써. L08 MIL의 re-localize ↔ re-train을 pixel 단위로 한 구조야.

L08 Weakly-Supervised Learning I

  1. Weak supervision: lower degree (or cheaper) annotation at train time than the required output at test time.WSOD가 대표 예야: test 때 box를 내야 하는데 train엔 class 이름만 줘. p.4
  2. MIL: each image is a bag of candidate windows, and only the bag label is known.bags = images, instances = windows야. 어느 window가 물체인지는 안 알려 줘. p.15
  3. Standard MIL alternates re-train and re-localize; it is sensitive to initialization and prone to locking.box로 detector를 학습하고 detector로 box를 다시 골라. locking = 틀린 box가 계속 뽑히는 악순환이야. p.16, p.23
  4. Re-localize picks the highest scoring window, so there is only one positive instance per image.arg maxb A(xb). supervised detection과 달리 positive 사진의 negative도 안 써. p.20–21
  5. Relaxing max: replace the hard max with log-sum-exp to learn from multiple high-scoring proposals."Hedge your bets". initialization에 덜 민감해져. p.22
  6. Multifold MIL: train on positives in all folds but k and all negatives, so the detector localizes images it has never seen.cross-validation처럼 해서 자기가 학습한 box를 또 고르는 걸 막아. p.24
  7. Objectness is a class-independent prior that guides WSOD toward complete objects.arg maxb λA(xb) + (1−λ)Obj(b). 배경과 부품 대신 물체 전체 쪽으로 밀어. p.28
  8. WSDDN: the first end-to-end WSOD method; the classification stream scores classes per region, and the localization stream compares regions per class.두 stream을 곱하고 proposal을 합쳐서 image label로 학습해. p.34
  9. WSDDN detects discriminative parts and does not learn bounding box regression.multiple positive instances와 positive 사진의 negative instances도 못 써. p.35
  10. OICR: WSDDN sets the initial instance labels, and an instance classifier iteratively refines them.WSDDN → Pseudo labels → Instance classifier → Better pseudo labels. 사진이 아니라 instance를 직접 분류해. p.36
  11. PCL: OICR uses a single pseudo object per image, but PCL uses clusters as independent pseudo objects.top-ranking proposals로 undirected graph를 만들고 연결이 많은 vertex를 cluster centre로 뽑아. p.37
  12. Concrete DropBlock drops the most relevant regions, so the detector must attend to the entire object.detector(w)는 loss를 줄이고 DropBlock(θ)은 loss를 키워: arg minw maxθ. p.38

L09 Weakly-Supervised Learning II

  1. Weakly supervised segmentation uses image-level labels at training time to produce pixel-level labels at test time.정답 mask를 직접 안 주니까 indirectly supervised야. p.4, p.19
  2. Priors are what we believe independent of any particular image; hints are indirect supervision received for each image.prior = size · shape · boundaries · saliency 같은 믿음, hint = image label · click · box · scribble 같은 사진별 label이야. p.5
  3. Gradient saliency is extremely noisy (salt-and-pepper); SmoothGrad adds noise, computes a gradient for each copy, and averages the gradients.pixel 단위 민감도라서 점이 흩어져. 평균 내는 건 사진이 아니라 gradient야. p.21–22
  4. CAM removes the FC layer, adds GAP, and sums the last feature maps with the class weights, so no separate gradient calculation is needed.Mc = Σk wkc fk. class마다 지도가 하나씩 나와 (per-class maps). p.24–26
  5. Thresholded CAMs give seeds: high scores become foreground, and low scores become background.확실한 영역만 seed로 써서 첫 학습 data를 만들어. p.27
  6. CAM masks are not sharp and focus on the discriminative area only.경계 문제(1번)와 범위 문제(2번). 뒤의 방법들이 이 둘 중 어느 쪽을 고치나로 나뉘어. p.28
  7. SEC: Seed keeps CAM seeds, Expand uses image-level labels via GWRP, and Constrain aligns masks to boundaries with a CRF.loss 세 개를 같이 걸어. GWRP와 CRF의 자리를 바꾼 지문이 함정이야. p.31
  8. CAM gives class-specific but partial localization; saliency gives the complete object extent but is class-agnostic.Oh는 둘을 Guide Labeller로 합쳐 class-specific pseudo mask를 만들어. p.34
  9. SEAM enforces that activation maps are equivariant (not invariant) to input transformations.원본과 affine 변환한 사진의 CAM을 변환을 보정해서 맞춰 (ER · ECR loss). p.35–36
  10. Hide-and-Seek hides random patches; adversarial erasing erases the most discriminative region the classifier currently uses.둘 다 다른 부위를 보게 만들지만, 가리는 곳을 고르는 방법이 달라. p.37, p.39
  11. Webly supervision trades annotation cost for label noise; Web-SEC learns a pixel classifier from clean, single-object web images.Model-T가 web 사진을 filter하고 target 사진의 CAM을 만들어. 두 label을 fuse해서 최종 model을 학습해. p.44–47
  12. Boxly: "Convnets are robust to noise" — train on rough box masks, then use the predictions as pseudo-labels for the next round.round를 거듭할수록 mask가 좋아지고, 좋은 초기 mask면 full supervision의 ~95%까지 가 (slide title: "GrabCut++", 그래프 범례는 Grabcut+). p.56–60
  13. CD-CLIP compares patches by their class distributions using JS divergence: CDA completes the CAM, and SBE fixes the boundaries.JS가 작을수록 같은 영역이야. boundary loss는 super-class가 2개 이상일 때만 걸어. p.65–74
  14. Liu et al. store captions, not images, and use the web as external memory; WISH maps tags, points, and boxes into SAM's prompt space.Liu: class name이 사진을 찾고 caption이 label을 정해. WISH: 섞인(heterogeneous) weak label을 한 모델이 배워. p.81–82, p.88
